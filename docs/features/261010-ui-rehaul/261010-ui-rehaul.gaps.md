# 261010 UI 重构：逐屏差距清单

规格在 [261010-ui-rehaul.design.md](261010-ui-rehaul.design.md)（§4 逐屏规格、§6 QoL 优先级），
这一份只记「规格写了什么 / 现在到哪 / 还差什么」，按**差距大小**排序，不重述设计理由。

打勾 = 与规格一致；「偏」= 与规格不同但属有意取舍；「缺」= 规格要求、尚未做。

## 三、round 7（2026-10-10 下午）动过的

- 回顾抽屉的第一段改名 **剧本**，内容从「说过的话」扩成**整条演出时间线**：新增 `packages/stage/src/scriptFeed.ts` 的 `buildScriptFeed`，把谱系里的布景节点（scene / actor / sfx / cg / fx / preload / stop）按 seq 插进台词流；停止点连选项一起列。删掉昨天加的角色筛。
- 有语音的台词挂一枚圆形喇叭徽章（先做成「回听」胶囊，用户否了：按原样保留圆喇叭）。
- 全站关闭键统一成一套圆键（面板 / 弹窗 / 灯箱 / 音色库 / 通知条），回顾抽屉那枚实心蓝方块换成暗玻璃圆键。
- `<ending>` 确认是设计如此（只防续写、不呈现；要呈现用 `<title>`），剧本页不为它留行。

## 四、round 6（2026-10-10 下午）动过的

- 通知横幅全部改成浮层：不再把标题与内容顶下去，落在标题栏下面（各屏 `--notice-top`；工坊按内容区居中）。同屏两条走 `.notice-layer` 叠放。
- 素材页顶上的「素材齐了」改成说清判据的「立绘 ✓ 背景图 ✓ / 还缺 …」+ 一行说明。
- 回顾（Log）：进面板自动把「当前这一句」滚进视野。（按角色筛当天加、当天按用户意见去掉——一部长戏靠筛找人不如直接搜。）
- 通知条样式现代化：圆角 14、玻璃底 + 分层阴影、按类型（错误/警告/回执）着色的左轨与墨色，全部取自主题令牌（原先写死浅色，深色主题下会浮出奶白块）；`.notice-close` 统一 32×32 圆钮。
- 顺带修掉一处重复的 `.error-banner` 规则（文件末尾那条把浮层定位又顶回页面内）。

## 五、round 5（2026-10-10 下午）动过的

- 未保存改动拦截：新增 `workshop/dirtyGuard.tsx`（登记处挂在 App 最外层），五个页面把自己改没改登记上来；切 tab / 回舞台 / 退出工坊 / Esc 都先问一句。
- 路线面板：窄屏把镜头控制（回到开头 / 最新 / 缩放 / 看全树）从面板头挪到底部一条，图例与画布各自让开；`StagePanel` 为此加了一个可选 `className`。宽屏不动。

## 六、round 4（2026-10-10 下午）动过的

- 断线状态：工坊在**连过再断**时出常驻横幅、禁输入与发送；「还没连上」不再误报；`onSendDropped` 的 toast 在工坊视图里不再重复弹（会盖在横幅上）。
- 设置页：窄屏分组可折叠（≤900px），导航点击自动展开目标组；≥901px 该状态完全不生效。
- 剧目页：宽屏（≥1080px）两列表单。

## 六、round 3（2026-10-10 下午）动过的

- 素材页：立绘卡的四个声明折进「声明」一行（摘要写声明过的值，一条没有就写缺省）；段头三颗动作键原本每颗都吃 `margin-left: auto`，被摊成「标题 …… 差分 …… 出图 上传差分」，改成只有第一颗吃。
- 对话页：失败条加「重发上一条」（拿最后一条 user 文本走 `workshop.chat`）。
- 设置页：保存中按钮态 + `.ok-banner` 保存回执（5 秒自动收起，不再与失败共用橙色警示条）。

## 七、round 2（2026-10-10 上午）动过的

- 剧目库铺满视口：去掉三块 `max-width: 1200px` 的居中栏，边距改流体；搜索空态补 `width: 100%`。
- 工坊设置页：加「其余设置在哪」两行去处 + 作用域说明，720 列居中。
- 工坊记忆页：名单分「常驻设定 / 设定卡」两组，改左名单 + 右编辑器两列（窄屏上下排、名单两列）。
- 工坊对话页：阅读栏宽 900（输入行同轴）、markdown 表格与代码块样式、音频换紧凑胶囊、素材条 96px 画廊且先图后声、素材缩略图类名作用域收口。
- 工坊文件页：树 280、只读移到详情、空态换成图标 + 去处说明。
- 服务端：`errors.ts` 的 `userFacingError` 把 `AbortError / Request aborted / fetch failed / 超时` 换成人话（原文进日志），工坊与剧作家两条失败路径都接上。
- 保存行：卡片内（记忆页编辑器）不再画通栏底色、补卡片底色（否则钉住时正文透出来）。
