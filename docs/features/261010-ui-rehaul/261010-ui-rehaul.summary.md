# ui-rehaul 交付现状

截至 2026-10-10 13:4x（worktree `feat/modern-ui-rehaul`，尚未提交）。

## 做了什么

- **样式令牌**：Studio（工作台：纸面 light/dark）与 Stage（舞台：玻璃 + 剧目主题）两套变量分家，时间类变量统一 `--fade-ms` / `--move-ms` / `--act-ms` / `--trans-ms` / `--fx-ms`，`prefers-reduced-motion` 下全部归零（实测立绘 `transition-duration` 变 `0s`、标题插画 `animation-name: none`）。
- **舞台**：常驻侧栏改成 Quick Menu（Auto / Log / Route / CG / Title）；回顾、路线、画廊变成舞台内嵌面板；台词条 / 名牌 / 选项 / 导演栏重做；导演栏窄屏收成图标。
- **工坊**：左轨 + 内容 + 任务条；八个 tab（对话 / 剧目 / 角色 / 记忆 / 素材 / 文件 / Agent / 设置）；会话与线程下拉；编辑页保存键钉在滚动区底边。
- **剧目库 / 周目 / 设置**：卡片矩阵、指标条、筛选胶囊；周目卡的操作行；设置页九组胶囊导航 + 常驻底栏 + 启动参数行落在内容末尾。
- **窄屏（≤720px）整套**：21 个页面/面板零横向溢出、零被裁元素、零竖排中文；核心动作单手可达（选中项自动滚入可视区、底缘保存键、底缘任务带）。
- **QoL 修复**（本轮与上几轮）：画廊空态补图标与两个去处；回顾默认落在「台词」栏；灯箱支持左右划翻页；立绘差分文件名不再被截成「n…」；断线时舞台动作不再静默丢弃（toast 说明）；`viewport-fit=cover`；设置页输入框与 ATRI 菜单补回键盘焦点环；工坊底缘任务带改纸面令牌（原先白底白字）。
