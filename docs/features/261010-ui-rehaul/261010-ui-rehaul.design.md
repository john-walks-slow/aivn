# AIVN 全界面重设计规格书

> 日期：2026-10-10  
> 范围：React 19 + Vite 前端；不改服务端协议。  
> 目标：把 AIVN 从“能跑的原型”提升为“想玩的视觉小说 + 用得顺手的创作工作台”。

## 1. 设计结论与原则

### 1.1 两种产品模式

AIVN 不是把工作台皮肤换成游戏，也不是把游戏塞进 IDE。它有两个明确模式：

- **舞台（Play）**：全屏、低干扰、以画面和台词为主。默认只显示台词框、必要的继续/选项和极简 Quick Menu；所有引擎术语改成玩家听得懂的动作。
- **工坊（Create）**：高信息密度、可扫描、可撤销、可持续编辑。采用编辑器式布局、固定导航、任务状态和保存反馈。

共同部分只共享颜色语义、字体、焦点环、按钮行为和状态色；舞台玻璃层不污染工坊纸面令牌。

### 1.2 对“回顾/路线/工坊是否都融入舞台”的判断

**回顾和路线融入舞台，工坊保留独立工作区入口。**

- 回顾是玩家在阅读时的即时动作。把它做成舞台内抽屉（Log），打开后保留当前背景和上下文，关闭即回到原句，符合视觉小说习惯，也避免“回顾页”把玩家踢出情绪。
- 路线是玩家对当前故事的回溯/跳转动作。它做成舞台内全屏 Flow 面板，选节点后可回到舞台或执行重写；它不应成为一个与“玩”并列的后台产品。
- 工坊的编辑对象多、操作时间长、需要持续滚动和并行任务。硬塞进舞台抽屉会让输入、文件树、素材卡和生成队列互相遮挡；保留独立 Studio 入口更符合用户心智。标题页提供“工坊”，舞台 Quick Menu 提供“打开工坊”，进入后是完整工作台而非浮层。
- CG 保留为舞台内 Gallery 面板，也可从工坊素材页进入。它是游玩成果浏览，不是编辑器导航。

不改变现有服务端模型：Log 读取已有 transcript，Flow 读取已有 lineage/route，Studio 继续复用同一条舞台连接、同一批 pending jobs。

### 1.3 现有基线问题归纳

基线截图显示：米色文档式外观缺乏产品层级；标题页有氛围但文字压在复杂背景上；舞台的英文控件、黑色选项条、导演按钮和台词框争夺焦点；回顾/路线/CG 的入口像后台页面；工坊顶部八个 Tab 在窄宽度下拥挤，聊天消息像日志 dump；设置、空态、周目和文件页存在大量空白或底部裁切；角色 id、`Request aborted`、未渲染 Markdown 等技术细节泄漏到用户界面。重设计必须优先解决层级、可读性、状态和空间利用，而不是单纯换色。

## 2. 信息架构与导航

### 2.1 顶层路由

```text
剧目库 /                       # 所有剧目
全局设置 /settings              # 应用级设置
剧目标题 /play/:id             # 沉浸式标题画面
周目选择 /play/:id/saves       # 一个剧目的多棵故事树
舞台 /play/:id/stage           # 当前周目；默认进入 Play
工坊 /play/:id/stage?view=studio&tab=...  # 同一连接的 Studio 工作区
```

旧 `view=backlog|route|cg` 可解析为舞台内面板状态，避免旧链接失效；新链接可使用 `panel=log|flow|gallery`。工坊 tab 仍由 `tab=` 解析，`workshop=1` 作为兼容入口。

### 2.2 进入/退出/快捷键

| 视图 | 进入 | 退出/返回 | 桌面快捷键 | 窄屏 |
|---|---|---|---|---|
| 剧目库 | 根路由、标题页“剧目库” | 进入剧目标题 | `G` | 顶栏变单行，搜索/设置收进菜单 |
| 全局设置 | 剧目库右上“设置” | `Esc`/“返回剧目库” | `,` | 分组折叠，底部保存栏固定 |
| 标题画面 | 点剧目卡 | `Esc`/“剧目库” | `T` | 菜单底部抽屉，标题和背景保持可见 |
| 周目 | 标题页“切换周目” | `Esc`/“返回标题” | `S` | 卡片单列，操作菜单收进 `…` |
| 舞台 | 标题“开始/继续” | Quick Menu“退出”回标题 | `Esc` 打开 Quick Menu；`Space/Enter` 推进；`Ctrl` 快进 | 手势点按推进，左上唤出 Quick Menu |
| 回顾 Log | Quick Menu“回顾”、舞台上滑/PgUp | `Esc`、下滑、关闭 | `L`/`PageUp` | 全屏抽屉，顶部保留“回到当前” |
| 路线 Flow | Quick Menu“路线” | `Esc`/“回到当前” | `F` | 节点横向滚动，工具栏固定底部 |
| CG Gallery | Quick Menu“画廊” | `Esc` | `C` | 两列网格，灯箱左右滑动 |
| 工坊 Studio | 标题“工坊”或 Quick Menu“工坊” | 顶栏“回到舞台”、`Esc`（若无 Modal） | `W` | 轨道改底部导航/抽屉 |
| 工坊会话 | Studio 的“对话” | 切 tab；会话列表不离开 Studio | `1` | 会话选择器固定在输入框上方 |
| 工坊各页 | Studio Rail | 切 Rail；不另开路由 | `2` 剧目、`3` 角色、`4` 记忆、`5` 素材、`6` 文件、`7` Agent、`8` 设置 | Rail 为可横滑 tab 或“更多”抽屉 |

快捷键只在非输入控件中生效；输入框、编辑器、Select 内不劫持。按钮不同时提供“返回”和“关闭”两个表达同一动作：面板右上统一 `×`，离开产品层级统一“回到舞台/标题”。

### 2.3 舞台 Quick Menu

默认隐藏在台词框右下或屏幕边缘，悬停/触摸后出现；不做常驻左侧栏。内容顺序：

```text
自动  语音  回顾  路线  画廊  保存  工坊  退出
```

“返回/隐藏”只保留一个“隐藏界面”动作；关闭 Quick Menu 不影响舞台。生成任务有未读变化时，工坊旁显示数字点，点击进入 Studio 后仍能看到同一队列。

```css

--shadow-md: 0 8px 24px rgb(16 24 40 / .14);
--shadow-lg: 0 18px 56px rgb(0 0 0 / .24);
--dur-fast: 120ms; --dur-normal: 200ms; --dur-slow: 360ms;

--ease-emphasized: cubic-bezier(.22, 1, .36, 1);
```

工作台卡片不超过 `8px` 圆角；舞台玻璃可用 `12px`。统一 `:focus-visible` 2px accent 环；`prefers-reduced-motion` 时所有转场不超过 1ms，禁用 Ken Burns、闪光、抖动。

## 4. 逐屏规格

### 4.1 剧目库 Library

```text
┌ AIVN ───────────────── 搜索剧目  [+ 新建] [导入] [设置] ┐
│ 最近游玩                                               │
│ [封面] 标题       [封面] 标题       [封面] 标题          │
│       周目/更新时间        周目/更新时间                  │
│                                                          │
│ 全部剧目                              排序: 最近更新 ▾    │
│ [剧目卡] [剧目卡] [新建剧目]                            │
└──────────────────────────────────────────────────────────┘
```

卡片封面 `3:4`，标题最多两行，简介最多两行，角标只显示“未开始/第 2 周目”；悬停显示“继续/打开标题/工坊”快捷动作，卡面本身进入标题。空态用一张低对比舞台插图 + “还没有剧目” + “新建剧目/导入剧目包”。加载用 6 个骨架卡；错误显示可重试条；导入中显示文件名和进度，不阻塞页面。手机一列或两列（宽度 >= 420px 两列），顶栏操作收进 `…`。

最终文案：`搜索剧目`、`最近游玩`、`全部剧目`、`还没有剧目`、`新建剧目`、`导入剧目包`。删掉“建一个开始”等重复说明和内部 id。

### 4.2 全局设置

使用左侧分组 Rail + 右侧单栏表单，固定底部保存条；分组：模型网关、长会话、生图、语音、联网检索、局域网、外观。每组只保留对决策有帮助的 help text。敏感值保留掩码行为，不显示可推断的真实前缀。

```text
┌ 设置 ─────────────────────────────── [保存] [放弃] ┐
│ 模型网关 │  模型网关                                  │
│ 长会话   │  [字段]                                   │
│ 生图     │  [字段]                                   │
│ 语音     │  [字段]                                   │
│ 网络     │  [字段]                                   │
│ 外观     │  [亮/暗/跟随系统] [强调色]                 │
└──────────────────────────────────────────────────────┘
```

加载显示分组骨架；读取失败显示“设置加载失败”+重试；保存中按钮写“保存中…”且仍能滚动；保存成功 Toast：“设置已保存，正在演出的内容会在本轮结束后更新”；错误原地贴近字段。窄屏 Rail 变横向可滑分段控件，保存条固定底部且不遮输入。

### 4.3 标题画面 Title

背景铺满，叠一层从底部到中部的可调暗渐变，不使用卡片包住标题。左下是标题、短 premise、角色名；右下是菜单：`继续（最新周目）`/`开始新周目`、`切换周目`、`工坊`、`导出剧目包`，危险操作放在“更多”内。没有存档只显示“开始新周目”。

加载先显示底色和标题骨架；无封面使用低对比渐变和“暂无封面”；缺素材不阻止开始，显示一条可关闭提示：“部分素材还没准备好，仍可开始。”删除使用 Modal 明确列出剧本、素材和周目。窄屏菜单底部半透明面板，标题保证露出 30% 下一层背景。文案删掉“stub”、引擎内部“演出”。

### 4.4 周目 Saves

```text
┌ ← 标题       周目                         [开始新周目] ┐
│ 当前周目                                               │
│ [01] 春日线  进行中  12 段内容  刚刚更新  [继续] [···] │
│ 其他周目                                               │
│ [02] 初次尝试          4 段内容  昨天     [进入] [···]  │
└──────────────────────────────────────────────────────────┘
```

卡片内容统一，不因当前态换按钮体系；当前态用 accent 边框和“进行中”徽标。`···` 菜单含重命名、删除。空态：“还没有周目”+主按钮。加载骨架；错误可重试。窄屏单列；删除 Modal 显示“将删除整棵故事树，无法恢复”。

### 4.5 舞台 Theater

```text
┌ [菜单]                                      [任务·2]  ┐
│             全屏背景 / CG / 立绘                    │
│             （无默认呼吸、无默认压暗）                │
│                                                       │
│  [白底·角色色描边 名牌]                               │
│  台词文本                               [语音/推进]   │
│                 ◇                                      │
│                           [自动][回顾][路线][工坊]     │
└───────────────────────────────────────────────────────┘
```

台词框为底部玻璃层，最大宽度 `min(920px, calc(100vw - 32px))`；名牌悬挂在台词框上沿。选项在画面中下部单列/两列，统一宽度，数字快捷键 1-9，悬停和键盘选中有明显边框。导演 Dock 默认收成右上一个带数字的图标按钮，点击展开动作：`插一句`、`改写这句`、`重新生成这一轮`、`生成插图`、`任务队列`；动作名直说结果，不出现“演出”。生成中 Dock 显示队列数量和当前任务，任务完成 Toast，不遮台词。

状态：首次进入显示“点一下开始”；流式显示“正在生成下一段…”并保留上一句；语音 pending 显示小型波形；断线显示“连接已断开，正在重连…”；失败保留“重试”并说明具体动作；结局不显示多余“继续”。回顾抽屉打开时舞台暗化/轻模糊，当前句定位高亮；路线/画廊采用全屏面板且保留返回当前。窄屏台词框加底部安全区，Quick Menu 变底部抽屉，选项单列，导演 Dock 变右下圆形按钮。

### 4.6 回顾 Log

从舞台内右侧滑入，宽屏 `420px`，也可扩成 720px；顶部固定“回顾”和“回到当前”。按时间倒序或当前句附近定位，角色名使用显示名；语音行可重听，玩家输入用“你”。原始 DSL 不放默认列表，只在“查看生成细节”折叠区内等宽展示。空态：“还没有可回顾的内容”；加载骨架；错误可重试。`Esc`、上滑关闭。

### 4.7 路线 Flow

全屏画布，顶部固定缩放/定位/回到当前，底部固定节点操作。节点卡统一 `240×148px` 最小尺寸，背景图右半淡入，正文覆盖不透明纱；显示时间、首句、角色显示名。点击选中后一次遍历标记来路/去路/将被删除范围；卡内动作保留文字“跳转/重写/删除”，避免图标猜测。无路线显示“故事还没有分支”；加载显示画布骨架；错误显示重试。窄屏使用横向/双指缩放和底部操作栏，禁止节点溢出视口而无法返回。

### 4.8 CG Gallery

舞台内画廊使用 4:3 或原图比例网格，支持按场景/周目筛选；生成图和素材图用小角标区分，灯箱显示来源和生成提示词（默认折叠）。空态改为图标 + “还没有插图” + “回到舞台生成” + “在工坊管理素材”两个动作按钮。加载骨架 6 格；资源失效显示占位和“重新载入”。窄屏两列，灯箱左右滑。

### 4.9 工坊总览与会话

工坊独立全屏工作区：左侧 `224px` Rail（对话、剧目、角色、记忆、素材、文件、Agent、设置），中间内容，右侧可选任务抽屉。Rail 底部显示连接状态和“预览舞台”。不再用顶部八个挤压 Tab。会话是对话页内部下拉/列表，不占主导航。

```text
┌ AIVN / 剧目名   [回到舞台]                         ┐
│ Rail │ 会话：未命名会话 ▾  [+]                     │
│      │ ┌ 助手消息 / 思考折叠 / 工具结果 ┐          │
│      │ │ 图片、音频、文件按结果分组       │          │
│      │ └─────────────────────────────────┘          │
│      │ [输入消息………………………………] [发送]            │
│      │ [连接正常]                                    │
└──────────────────────────────────────────────────────┘
```

消息中 `思考` 默认折叠，工具调用显示人话标签；图片为画廊，音频为紧凑播放器，错误改为“这次请求没有完成”+“重试/删除”，不展示 `Request aborted`。流式、等待、断线、空会话、历史加载均有明确状态。输入支持 Enter 发送、Shift+Enter 换行；生成期间仍可查看其他页但任务条固定在内容底部。窄屏 Rail 变底部五项常用入口 + “更多”抽屉，任务条不覆盖输入框。

### 4.10 工坊各页

- **剧目**：两列表单，标题/开场白/语言/默认音色/封面/写作参数；分组标题短，保存状态固定在右上。封面选择直接展示缩略图，支持恢复自动选择。
- **角色**：角色卡网格，头像/立绘缩略图/显示名/音色/立绘绑定；点卡进入编辑，主角不可删除但操作一致；新建先填 id，用户可见错误就地显示。窄屏单列。
- **记忆**：左侧卡片列表按“常驻设定/按需读取”分组，右侧编辑器；显示名优先，内部路径收进详情。空态提供“新建设定”。
- **素材**：按立绘、背景、插图、音乐、音效分段；立绘卡显示大缩略图、差分条和绑定角色，生成/上传/删除在卡头，参数折叠。生成中卡片保留占位和进度；失败可重试。窄屏分段折叠，避免一屏塞完。
- **文件**：左树宽度 `280px`，右侧编辑/预览；文件名不截断到无法识别，`只读` 仅在详情显示。未选文件显示图标 + “选择一个文件开始查看”。加载、保存中、只读、解析错误分别呈现。
- **Agent**：剧作家、搭台助手两张配置卡；模型、思考档位、能力按组显示；锁定能力写“始终开启”，不可用能力给原因。保存成功显示“已保存”。
- **工坊设置**：只放本机演出开关（语音、无选项轮次显示继续），作用域写在每组标题下：“仅保存在此浏览器”。服务端设置只给链接“打开全局设置”，不重复表单。

## 5. 导演工具与任务队列

### 5.1 展开逻辑

导演 Dock 三态：`collapsed`（默认，仅图标和未读数）、`expanded`（动作列表，点击外部收起）、`modal`（输入动作的 Modal）。舞台点击/推进不受 Dock 影响；选肢层只覆盖画面区，不覆盖台词和 Dock。`H` 仅控制全局 UI 隐藏，不与 Dock 抢同一快捷键。

动作映射：`插一句`进入队列；`改写这句`修改当前 line；`重新生成这一轮` fork 当前 beat；`生成插图`落到当前节点；`重听`只在有语音时显示。对同一结果不并排放两个控件，例如只保留一个“回到舞台”，不再同时出现返回键和关闭键。

### 5.2 队列

PromptQueuePanel 使用现有 `pendingJobs`/`queue`，舞台 Dock 展开后显示最近三项，其余点击“查看全部”。任务行包含类型、简短目标、状态、取消/重试；生成中的轮次、插图、语音使用不同图标和文字；失败不自动消失，写明“生成插图失败”而非内部异常。工坊任务栏固定在内容底部，不覆盖素材页页头。所有任务从舞台切到工坊仍可见，不新建连接、不复制状态。

### 共享包谨慎项

- `packages/stage/src/stage.css` 是 DSH 插件宿主也使用的样式。所有令牌和选择器必须挂 `.stage-root`，不得写 `:root`、全局 `button` 或宿主假设；时间变量必须带 `ms` 单位。
- `StageTheater.tsx`、`StopPanel.tsx` 的 props 与语义会影响 DSH。优先只改 DOM/CSS 和可选 props；不删除现有 `directorBar`、`overlay`、`onView` 能力。舞台 z-index 必须隔离背景栈、立绘层、CG 层，修改后用 `elementFromPoint` 验证。
- 不把 Studio token、字体和表单规则写进 stage.css；Studio 只在 `apps/web/src/app.css` 或组件作用域内实现。
- `StageShell`/路由改变后，同时验证标题进入、周目进入、舞台退出、Quick Menu、旧 query 兼容，以及 DSH 宿主中没有舞台外壳时的独立渲染。
- 不新增大型 UI 框架；继续使用 React、现有 Modal、lucide Icon。轻依赖只有在无法用现有 CSS/DOM 解决时才考虑，路线布局继续沿用 `routeTree.ts` 的单一真相源。
