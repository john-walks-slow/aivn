## 一、标题菜单的语言，以及危险操作放哪

![标题菜单 A/B](<../../screenshots/m12/56-decision-title-menu.png>)
*上：现状（CONTINUE / START / LOAD / WORKSHOP，ATRI 一比一）；下：中文备选（继续 / 开始 / 读档 / 工坊）*

- **现状**：英文。来自你「游戏标题与舞台界面一比一参考 ATRI」的指示；ATRI 的菜单就是英文。
- **冲突**：更早的设计规格写的是中文菜单，且项目有一条「玩家界面禁用引擎内部词」——中文备选更贴玩家。
- **顺带一问**：`导出 / 删除` 现在和「继续」并列在标题页上，误触代价高。要不要收进一个「更多」里？
- **我的建议**：若这条线是「致敬 ATRI」，保留英文；若定位是中文玩家的产品，换中文并收危险操作。

## 二、指标卡与快捷键标签的英文

![指标卡 A/B](<../../screenshots/m12/55-decision-metric-labels.png>)
*上：现状（ALL PLAYS / ACTIVE PLAYS / TOTAL SAVES / ENGINE STATUS）；下：中文备选*

- **现状**：指标卡是英文大写标签（OMC 工业风），快捷菜单是 `Auto / Log / Route / CG / Title`。
- **注意**：改中文会出现「周目记录 / 15 周目记录」这种上下重复，副标签要一起改。
- 有关的还有两处，都不一定算问题，一并给你判断：
  - `state.json（state）` 这类卡片标题：出现在工坊的剧目/文件面板里，是对着**剧作家**说话的，写文件名是合理的。
  - 剧目卡左上角的内部 id 徽标（`320000` / `stub` / `test2`）：这个在**玩家**看的第一屏上。按你「玩家界面禁用引擎内部词」的规矩它该去掉；但你也可能在用它对照数据目录里的剧目，所以我不擅自动——**这一条你说去掉我就去掉**。
- 我 Originally 把 `apps/web/src/workshop/PlayPane.tsx` 里的 `<say id="passerby">` 也列了进来，复核后**撤回**：它在工坊的剧目面板里，是给剧作家解释「哪种一次性角色默认不出声」的语法示例，属于该出现的地方。
- **我的建议**：指标卡保留英文（它是这套工作台的设计语言）；内部 id 徽标看你要不要留作对照。

## 三、说话人名牌的样式，与非说话者压暗

![名牌与压暗四选一](<../../screenshots/m12/54-decision-nameplate-dimming.png>)
*左上＝现状 / 右上＝白底名牌 / 左下＝不压暗 / 右下＝白底名牌且不压暗*

- **名牌**：你此前的裁决是「白底 + 主题描边色（纯文字看不清）」；后来 ATRI 那一版做成了**无底色白字 + 柔光晕**（浅色主题则翻成深墨字 + 白晕，两边对称，代码注释与实现自洽）——是有意覆盖，不是半成品，所以我没有擅自回滚。
- **压暗**：你此前的裁决是「默认都不开，只预留样式」；现状是**只要有人在说话，其他人压暗**。实测非说话者亮度 117.4 → 97.5（暗约 17%），说话者不变。
- **我的建议**：名牌选白底那版（清晰度确实更好，尤其背景花的时候）；压暗保留——它让「谁在说话」一眼可辨，代价很小。
