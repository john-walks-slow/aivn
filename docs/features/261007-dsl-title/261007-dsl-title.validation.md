# `title` 全屏文本卡 用户验证

## 验证说明

- 验证对象：Stage DSL 新增 `<title>` 全屏文本卡（章节标题/诗歌/独白），以及 `<scene bg>` 的纯色场
  扩展。核心是**视觉与交互**（对话框隐藏/恢复、五档对齐、逐句点击节奏、纯色场），单测只能覆盖
  解析/谱系/状态机纯函数，真实演出节奏与画面必须在真实运行环境里看。
- 环境/前置条件：
  - 本仓库 `pnpm -r build` 通过（已由实施方完成）。
  - 起应用：`pnpm --filter @aivn/server start`（同端口挂 `apps/web/dist`）；需要一个可用的 LLM 网关
    （设置页配置）。也可 `pnpm --filter @aivn/web dev` + server 开发态。
  - 新建一个剧目（或复用），在「工坊」里给它配好可用模型与一个背景素材（或直接用纯色场，无需素材）。
  - **提示词已更新**（`apps/server/src/prompt.ts` 的《全屏标题卡》章），模型应能按下面的口令写出
    `<title>`。
