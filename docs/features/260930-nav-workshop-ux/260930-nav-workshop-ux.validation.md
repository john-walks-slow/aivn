## 实测揪出的两个计划外缺陷

1. **「图标没居中」的真因是全局 `button { padding: 9px 14px }`**：32px 方块键内容框被挤成 4px，图标右溢出 7px（实测 dx=7）。凡自定宽高 + grid 居中的方块键都要 `padding: 0`（`.side-collapse`/`.side-drawer-btn`/`.view-bar-close`/`.modal-x`/`.dir-btn`）。计划里只打算「换图标 + 居中」，真因在 CSS 层。
2. **hash 变化不重挂同路由组件**：工坊入口点「舞台」曾是一记空操作（屏幕停在工坊、连接还是不开演那条）。`App.tsx` 改用 `route.query` 当 `key`，`goView("stage")` 不再留 `?view=stage`。
