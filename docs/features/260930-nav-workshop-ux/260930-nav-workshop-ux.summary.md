# 小结：导航与工坊界面一轮收口

## 交付了什么

11 条反馈全部落地，前端单方面完成：

- 标题页「继续（档名）」在前且为主按钮
- 折叠/唤出侧栏键换成专用 `panel-left-open/close` 图标、无边框幽灵键、真正居中
- 插一句 / 改台词 / 自由输入三处输入统一居中模态窗
- 选肢层只盖画面，台词条 / 导演栏 / 侧栏 / 排队面板照常可用
- 工坊去掉抽屉，成为舞台外壳的第四个视图（恒全屏、复用同一条连接）
- 工坊新增「设置」页收「无选项轮次间插入「继续」」+ 语音开关；`.env` 设置留在剧目库页
- 「创作口径」→「记忆」，覆盖 `memory/**` 四组（常驻设定 / 角色设定 / 设定卡 / 只读纪元产物）
- 「线程」→「会话」，下沉为对话页内部一层，不再占主导航
- 非舞台视图统一有视图栏 + `×`，`Esc` 同效
- 标题页直达工坊外壳一字不差，无顶栏跳变

## 计划外收获

浏览器实测揪出两个计划没料到的根因，都写进了 AGENTS.md「导航与工坊铁律」：

1. 图标不居中的真因是全局 `button { padding: 9px 14px }` 把方块键内容框挤成 4px（实测 dx=7px → 0）。
2. hash 变化不重挂同路由组件，工坊入口「回舞台」曾是一记空操作（`App.tsx` 改用 query 当 `key`）。

## 怎么用

- 侧栏四项：舞台 / 回顾 / 路线 / 工坊；非舞台视图右上 `×` 或 `Esc` 回舞台。
- 演出侧设置在工坊「设置」页；服务端 `.env` 在剧目库页「⚙ 设置」。
- 记忆在工坊「记忆」页改，改完等当前这一轮写完生效（与服务端 whenIdle 同一机制）。
