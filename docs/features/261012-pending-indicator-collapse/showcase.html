Pending Indicator 折叠态 Showcase

无字无光点，仅含浅图标与 spinner / 跳动光标。spinner 代表文本生成，变成跳动光标代表下一句可用；其他类别闪烁图标 ➕ 右上角小数字队列长度。

1. 文本生成中（Spinner 态） 剧作家创作流式写入
铃音
「……其实我一直在想，如果是那个时候的你的话……」
AutoLogMenu
2. 下一句可用（跳动光标态） spinner 变成跳动光标
铃音
「如果是那个时候的你的话，一定会毫不犹豫地伸出手吧。」
AutoLogMenu
3. 单项媒体生成（麦克风 1 项） 数量为 1 时仅显示闪烁浅图标
铃音
「不过，现在说这些也已经太晚了呢。」
AutoLogMenu
4. 多类别多任务队列（混合并排） 麦克风(2) · 音乐(1) · 图片(2) · 人像(1)
铃音
「海风很舒服呢……稍微再坐一会儿吧。」
AutoLogMenu
5. 复合状态：下一句就绪 ➕ 媒体生成中 跳动光标 + 麦克风(1) + 图片(2)
铃音
「无论发生什么，我都会在你身边的。」
AutoLogMenu
