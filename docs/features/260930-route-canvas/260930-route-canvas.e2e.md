## 体验类测试项

| # | 体验场景 | 关注点 | 观察 | 建议/问题 |
|---|----------|--------|------|-----------|
| 1 | 打开路线视图第一眼 | 时间推进方向、分岔认知、点击习惯与视觉暗示 | 顶部提示清晰指出「从左到右是时间 · 分岔点往下扇开 · 每张卡下面就是它的去向」，树形展开自然；卡片本身不再有 hover 选中交互或手型指针，点击卡片无响应，用户注意力会被引导到卡片下方的工具按钮。但习惯旧版“点击卡片”的用户初次上手可能会连续点击卡面 | 观察良好；设计符合四动词正交预期。建议卡片 hover 时光标保持 default，避免给用户“卡片可点”的假象（当前即为 default，体验得当）。 |
| 2 | 卡片工具按钮的可见度与触达感知 | 默认半透明态与聚焦/悬停态的区别；触屏无悬停环境下的操作发现性 | 默认状态下工具条 `opacity: 0.55`（文字浅灰 `rgb(92, 92, 92)`），在白色网格底板上字迹略浅，但图标（准星与分叉）轮廓仍然清晰；鼠标 hover 或键盘 focus 时平滑过渡到 `opacity: 1`。在窄屏/触屏模拟下，虽然没有 hover，但按钮由于常驻并带图标，位置稳定可点击 | 观察：当前 0.55 透明度兼顾了“突出台词内容、削弱按钮干扰”的目的；但对于视力较弱或户外强光下的触屏用户，浅灰字较淡。建议可评估将废弃分支以外的活节点默认透明度微调至 0.65~0.70。 |
| 3 | 整屏观感与概念一致性 | 卡片密度、贝塞尔曲线走向、留白与排版纯净度 | 画面留白充足，点阵背景与贝塞尔曲线衔接自然，主线与废弃分支用虚实线条区分明确（实线蓝色为当前活跃线，虚线半透明为废弃线）；完全剔除了旧概念的残留词汇与冗余 UI chrome，整体轻量优雅 | 整体设计非常清爽干净，视觉层级（当前拍蓝框与高亮线 > 历史拍卡片 > 操作按钮）主次分明。 |
