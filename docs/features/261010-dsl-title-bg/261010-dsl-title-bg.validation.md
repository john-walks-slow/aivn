# `<title>` 底色/字色 用户验证

## 验证说明

- 验证对象：`<title>` 全屏文本卡新增 `bg`（底色，缺省黑底）与 `ink`（字色，不写按底色配对比色），
  `bg="none"` 为显式透明。核心是**视觉**——自动化只能验到"计算样式对不对"（已用 headless 浏览器
  假流注入实拍三张，见 `docs/features/261010-dsl-title-bg/screenshots/`），
  **提示词有没有把这个契约讲清楚**（模型会不会主动写对）只能在真实模型上跑一次。
- 前置条件：dev 实例已在跑（链接见交付消息），设置页里配好可用的模型网关；任意剧目可开演。
- 关注点只有两个：默认是不是黑底白字、想叠层时知不知道要写 `bg="none"`。

## 验证项

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| V1 · 缺省观感：让剧作家「用一张章节标题卡开场」（不提颜色）。 | 整屏**黑底白字**，对话框隐藏；不再依赖前一行 `<scene bg="black"/>`。 | | 待验证 | 计算样式已验（黑底 `rgb(0,0,0)` + 白字 + 无投影） |
| V2 · 显式叠层：让它「把标题叠在场景画面上，不要铺底」。 | 卡面透明，场景可见；字色回舞台皮肤并带投影。 | | 待验证 | 同上（`bg="none"` → `background: transparent` + 皮肤投影） |
| V3 · 白底：让它「用白底的一张标题卡」。 | 白底黑字（字色没写也对），无投影。 | | 待验证 | 同上（`bg="white"` → 自动黑字） |
