# 舞台消息框：五种设计方向（远景）

起因是一句话：**消息框想换风格**。所以先不接开关，先把「换过去会是什么样」摆出来——
同一张画面、同一句台词、同一排快捷入口，只有消息框本身不同。每张图上半是深色、下半是浅色。

## 五种风格

### V1 · 浮岛玻璃卡
通栏换成一张悬浮圆角卡：毛玻璃 + 上缘一道高光细线；名牌做成卡沿上的一枚胶囊；快捷入口收在卡内底缘。
画面细节不被压掉，适合通用现代 AVG。

![V1 浮岛玻璃卡](shots/combo-v1.jpg)

### V2 · 电影字幕
去掉底板，上下压成宽银幕黑边，台词大字号居中，名牌是细字距的暖金小字，快捷入口退成字幕下方一行细字。
适合文艺、悬疑、以氛围为主的戏。

![V2 电影字幕](shots/combo-v2.jpg)

### V3 · 战术 HUD
切角面板 + 青色描边 + 扫描纹，顶上一行等宽标签（场景与序号），按键带方括号。
适合科幻、赛博、调查推理。

![V3 战术 HUD](shots/combo-v3.jpg)

### V4 · 书卷
双线内框 + 衬线正文，`❖` 起头的小字距名牌，快捷入口是一行文字而不是按钮；深色下是夜色纸、浅色下是宣纸。
适合古风、奇幻、文学改编。

![V4 书卷](shots/combo-v4.jpg)

### V5 · 丝绒幕
幕布式通栏（丝绒织纹 + 金色上缘线与菱形坠），台词居中收窄，金色胶囊按键；浅色下丝绒换成暖米织纹。
适合哥特、歌剧、暗黑悬疑。

![V5 丝绒幕](shots/combo-v5.jpg)

## 和现状的关系

现状是 ATRI 式通栏渐变（底部一条无框渐变带，名牌悬在正文左上方，快捷菜单是右下角独立胶囊）。
五种里三种是它的近亲（V1 / V3 / V5 都还是「底部一条带」），两种换了骨架（V2 去底板、V4 换卡片材质）。

真正要选的是三件事：

1. **要不要底板**——V2 完全不要；其余都要，只是材质不同。
2. **快捷入口摆哪**——V1 / V3 / V5 摆在面板内底缘，V2 摆在字幕下方居中，V4 退化成一行文字。
3. **名牌怎么站**——胶囊（V1）、细字距小字（V2 / V4）、等宽标签（V3）、金色短横（V5）。

## 重渲染

画面与立绘取自本机数据目录（`library/backgrounds/`、`plays/mh/assets/sprites/`），这两处都不进 git；
换机器前先改 `showcase.html` 里的两处 `url()`。

```bash
node docs/features/261012-stage-style-variants/render.mjs
# → tmp/style-variant-shots/{combo-v1..v5,all-dark,all-light,vN-{dark,light}}.png
```

## 要接通时怎么接（后话，现在不动生产样式）

五种风格的差异全在「`.theater-dialog` 及其子元素怎么画」，所以接通不必动 DOM：

- 风格挂在根上：`.theater[data-dialog-style="hud"]`，样式表按这一层展开；
- 开关进 `settings.json`（`ui.dialogStyle`，缺省 `atri`），与界面主题走同一套读写路径；
- 名字 / 正文 / 快捷菜单的类名（`.dialog-name` / `.dialog-text` / `.dialog-foot` / `.quick-btn`）五种通用，
  只换 CSS 就能整条换过去；只有 V2 要两条黑边元素、V4 要内框，这两处才需要碰 markup。

先把风格看定，再决定哪一种值得进设置页。
