# Stage-AI 视觉 2.0：把产品框架从「网页」换成「游戏画面」

2026-09-30 · 分支 `feat/game-ux`（不合并，先体验）

## 现状判据

现状截图（1440×900）自评：剧目库像 CMS 后台；标题页像详情页；舞台页像嵌了个播放器的工作台。
三处共性——元素在**滚动页面**里按纵向流排列，控件是**带边框圆角矩形**，画面被**容器内的一块内容**对待。

## 参考样本（modlens 实读）

| 作品 | 品牌 | 取到的界面 | 关键观察 |
|---|---|---|---|

| 千恋＊万花 | 柚子社 | 剧情演出 | 深炭底 + 金描边窗框；白字带投影；`Q.SAVE / Q.LOAD / SAVE / LOAD / AUTO / SKIP / LOG / CONFIG` 一条快捷菜单贴在消息窗右下 |
| Summer Pockets | Key | 剧情演出 | 半透明深蓝消息窗，白字；右下角羽毛形等待光标；名字牌浮在窗左上 |
| Fate/stay night REMASTERED | Type-Moon | 剧情演出 | 同构的消息窗 + 固定系统按钮 |
| 剧目库/标题/舞台（本项目） | — | 全站 | 滚动流 + 描边矩形按钮 + 无遮幅 |

同一族的共同结构，跨品牌都成立：

- **画面是主角**。背景/立绘铺满一个 16:9 的窗口，UI 全部浮在上面，窗口本身有边界（遮幅、描边、投影）。
- **消息窗不是通知，是家具**。固定在画面下部、有设计过的窗框、名字牌骑在窗沿上、快捷菜单是窗的一部分。
- **系统按钮是一条横排的短词**（SAVE/LOAD/AUTO/SKIP/LOG/CONFIG），不是图标网格，也不是设置抽屉。
- **旁白与台词分型**：旁白居中或用弱色，台词带名字牌、正文白色。
- **字承担气氛**：正文衬线/明朝，UI 无衬线；字距拉开。
- **深色窗 + 亮色字**，即便整体是明亮日常题材也一样——这是为了压得住背景图，不是风格选择。

## 设计决定

### 1. 全站套一个「游戏窗口」（画框层）

`#root` 变成哑光底 + 居中窗口，宽高由 `16/9` 公式反推；窗口有一圈 1px 描边和一圈外投影。
剧目库 / 标题 / 周目 / 舞台 / 回顾 / 路线 / 工坊全部装在这个窗口里——这是「不像 web ui」最省力也最彻底的一条。
窄屏（≤820px）改成铺满，去掉描边与投影，只保留一条状态栏底色。

### 2. 主题令牌换成「和紙 + 臙脂」，仍属浅色日常系

| 层 | 令牌 | 值 |
|---|---|---|
| 画框外 | `--frame` | `#2A2521` 深胡桃哑光 |
| 纸面 | `--paper` / `--panel` / `--panel-2` | `#F5F1E8` / `#FFFCF5` / `#EDE7DA` |
| 墨 | `--ink` / `--ink-soft` / `--ink-faint` | `#23201C` / `#5B5348` / `#9A9081` |
| 线 | `--rule` | `#DED5C4` |
| 主色 | `--accent` / `--accent-soft` | `#9B3B4F` 臙脂 / `#F4E3E2` |
| 副色（链接） | `--link` | `#2F5D7C` |
| 画面衬底 | `--stage-bg` | `#17130F` |
| 消息窗 | `--dialog-bg` | 深墨渐变 0.90~0.94 |
| 窗内字 | `--dialog-ink` / `-soft` / `-thought` | `#F2EBDE` / `#C6BBA9` / `#A9A6C4` |
| 名字牌 | `--nameplate-bg` | `#FFFCF5`（白底 + 主题描边，保留既有偏好） |

浅色系落在菜单/库/工坊这些**不上画**的地方；一上画（消息窗、快捷菜单、选肢）就切深色玻璃。
这不是两套风格，是同一部 AVG 的上下两层——`theme.css` 换皮时两层一起换。

### 3. 舞台：消息窗 + 名字牌 + 快捷菜单

- 消息窗：近直角圆角（2px）、1px 暖白描边 + 内侧发丝线、暖黑渐变底。四边留缝，仍是浮层，不改舞台高度。
- 正文：衬线 17px / 行高 2.0 / 米白带柔投影。**旁白居中弱色**，台词左对齐带名字牌。
- 名字牌：白底 + 主色描边，骑在窗沿左上，不做厚贴片。
- 快捷菜单：窗下沿右端一条横排，**中文短词 + 图标**（自动 / 重听 / 插一句 / 改写 / 重来）。
  带字样是项目既有决定（路线节点卡已经这么做），二十几像素的方块分不出「重听」和「改写」。
- 回顾/路线/工坊留在系统菜单（侧栏），不与快捷菜单重复。

### 4. 标题页做成真正的标题画面

背景取该剧目第一张 `backgrounds/` 素材（没有就走主题色和纸渐变），标题用衬线大字 + 拉开字距，
菜单从「横向排布的胶囊」改成**竖排动词列表**，当前主项用主色 + 左侧标尺标出。

### 5. 周目页做成存档位

一剧目 N 棵故事树 = 一排编号存档位（`01` `02` …），每格一张卡：位号、档名、段落数、落笔时刻、首句预览、动词按钮。
`現在の存档` 用主色边框 + 角标，不用整块底色。

### 6. 剧目库做成作品選択

卡片从「标题 + 徽章 + 段落」改成：衬线标题、副前提一行、细线分隔的状态行（`可开演` / `未就绪` 走文字 + 小方点，不走胶囊徽章）。
「新建剧目」不再用虚线框，改成同尺寸的标题牌 + 下方两个动词。

### 7. 系统菜单（侧栏）去 Saaia 味

剧目名块做成 logo 块（衬线 + 展开箭头），导航项改成竖排列表 + 左侧主色标尺 + 分隔线，当前项主色实底。
折叠/拖宽/窄屏抽屉的逻辑全部保留。

### 8. 工坊 / 设置 / 音色库

结构不动，只换皮：面板改「无阴影 + 发丝描边 + 2px 圆角」，按钮改直角浅底，标签改小字号 + 字距。
它们是工具区，该干净就干净；但用的是同一套令牌和同一条描边逻辑，进出工坊不换产品。

## 本次不做

- 标题画面图（BGM 试听、点击音、立绘开场动效）
- 侧栏彻底移除（保留信息架构，只换皮）
- 深色主题预设（令牌已分层，换皮时再加）
- 各剧目自带 theme.css 的样例
