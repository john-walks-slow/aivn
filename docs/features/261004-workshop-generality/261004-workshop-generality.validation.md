# workshop-generality 用户验证

## 验证说明

- 验证对象：搭台助手（工坊 agent）的文件工具从自造的 `read_file` / `write_file` / `edit_file` / `list_files` / `delete_file`
  换成 pi 内建的 `read` / `write` / `edit`，并按你的要求把「通用 agent」的最后一公里补上——`bash`（默认关，在「Agent」页手动勾）。
  需求与取舍见同目录 `261004-workshop-generality.plan.md`。
- 环境/前置条件：worktree `feat/workshop-shell` 起 dev（`./scripts/dev-worktree.sh`）；
  要真跑 agent 那一轮需要一个能用的 LLM 网关（`STAGE_API_KEY` / `STAGE_MODEL_BASE`）。
  不需要额外配置——`bash` 的开关就在原有的逐剧目工具开关里，没有新增环境变量。

## 验证项

### A. 换工具之后，日常改设定这条路没坏（最高优先）

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 工坊「Agent」页看搭台助手那张卡 | 「剧目文件」组里是 `read` / `write` / `edit`（不再是 `read_file` / `write_file`）；多出一个「命令行」组，里面 `bash` **默认没勾** | | 待验证 | |
| 对话里说「在 lore 里加一条：旧校舍将在文化祭后拆除」 | 它读现状再写盘；面板底部照旧出现 📝 撤销条，点撤销能把文件恢复成写入前的内容（新建的则删掉） | | 待验证 | |
| 说「把 premise 里第二段删掉，别的不要动」 | 走 `edit` 定点替换；改完只有那一段没了，旁边内容的 BOM / 行尾没被动过 | | 待验证 | |
| 说「现在有哪些设定文件」 | 它自己列出来（`read` 目录或 bash），不是回你一句「我看不到文件」 | | 待验证 | |
| 说「把 play.json 的 title 改成 XXX」 | 改成功、剧目标题跟着变 | | 待验证 | |

### B. 白名单与校验还在（回归风险最高的一处）

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 让搭台助手写 `assets/backgrounds/whatever.png` | 被拒，理由说明「不在工坊可写范围」，而不是真去写一张假 PNG | | 待验证 | |
| 让它读 `session.json` / `saves/` 下的东西 | 被拒，理由说明「不在工坊可读范围」——演出状态不进工坊的视野 | | 待验证 | |
| 让它写一份 `characters` 少了 `id` 的 play.json | 被拒，**文件在磁盘上一个字节没变**，模型收到的是「play.json 结构校验不过」 | | 待验证 | |
| 📁 文件页里翻 `assets/**` | 照旧只读、图片直接预览，不进编辑器 | | 待验证 | |

### C. 勾上 `bash` 之后（本次唯一新增的能力，也是最需要你亲自判断的一处）

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 「Agent」页勾上「命令行」的 `bash`，保存（不写 `.env`、不改任何环境变量） | 保存即写进这个剧目的 `play.json`；下一轮对话它就能用 | | 待验证 | |
| 说「用 grep 找一下 memory 里哪些文件提到过雨」 | 真的执行了命令并把命中结果读回来（在此之前它只能靠 `read` 一个个翻） | | 待验证 | |
| 让它用 `sed` / `mv` 改一个 memory 文件 | 文件真的变了；**这一步不产生撤销条**（bash 不经过写入回调）——这是设计取舍，确认你能接受 | | 待验证 | |
| 改完之后看舞台 | 改动**保存即生效**（runtime 重建了）——说明 bash 的改动被记账了，不是悄悄改完没人管 | | 待验证 | |
| 让它跑一条会失败的命令（如 `ls 不存在的目录`） | 报错原话回到对话里，不静默吞掉、也不把这一轮整体判失败 | | 待验证 | |
| 让它跑一条要很久的命令（如 `sleep 600`） | 在工坊单轮超时（约 7 分钟）时被掐断，不是永久挂着 | | 待验证 | |
| 关掉「命令行」的 `bash`，保存后再问「帮我 grep 一下」 | 它不再有这个工具（也不该在提示词里看到命令行那一章），会回到用 `read` 翻 | | 待验证 | |

### D. 提示词不再复述工具契约（这次顺手清掉的「暗规则」）

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 勾上 `bash` 后问它「你能在这台机器上做什么、边界在哪」 | 说得出 cwd 是剧目目录、改文件不进撤销条、单条命令没有自己的超时——这些原本一条都没写进提示词 | | 待验证 | |
| 让它出一张立绘（工坊出图，`generate_image`） | 画幅跟着这个角色的 `framing` 走（full 9:16 / half 3:4 / square 1:1）。原先提示词里那句写死的 9:16 已经删了，别再出现「半身角色被画成全身」 | | 待验证 | |
| 出一张不允许的图（比如让它画真人照片） | 拒绝的理由是原话转述的失败原因，不是一句含糊的「出图失败」 | | 待验证 | |
