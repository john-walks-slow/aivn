# 一轮没写出来时的兜底（判废 · 回滚 · 自动重试一次）

## 问题

剧作家偶尔交不出这一轮。三种形态：

1. **拒答**（模型不肯写）：裸散文被解析器当「DSL 之外的文本」丢弃 → 零事件；或包进
   `<narrate>` 直接当旁白演出去。
2. **空转**：只调了工具（`generate_image` 的 preload、记忆工具），一个字台词都没有。
3. **硬故障**：provider 报错（429/网关拒绝）、超时 240s。

引擎对这三种的处理有一处致命漏洞和一处体验坑：

- **护栏判据错了**：`finishBeat` 的空轮护栏数的是**事件数**（`beatEvents === 0`），而
  `scene/actor/sfx/cg/preload_asset` 全都算事件。所以「改了个背景 + 纯文本拒答」
  「只发起一张图、零台词」的轮次**有事件、零台词**，护栏不响，玩家拿到一个空舞台，
  它还被当成正常的一轮写进谱系、快照与 archive。
- **重试发的是缩水轮**：点「继续」时 `resolved = null`、steer 已出队，只发一条【状态】。
  模型看到的是「【状态】+（选择了：X）」→「我拒绝」→「【状态】」，既没被要求重做那个选择，
  也甩不掉自己那次拒答。而失败那一轮的谱系节点、对话体消息、`beat_end` 全部留着。
- 错误提示是一个 4 秒的 toast（`error` kind 其实是常驻的，见下），玩家手上的选择权
  已经在那次「继续」里花掉了。

## 方案

### 1. 判据：零台词，不是零事件

```
判废 = 本轮没有任何非空台词（say/narrate/thought） 且 没有交出停止点
```

- 控制指令（`scene`/`actor`/`sfx`/`cg`/`preload`）**不算内容**——只换了个背景、
  只发起一张图，舞台上仍然什么都没有。
- 交了停止点就算有产出：那是玩家的出口，纯「选择轮」不是失败。
- 交付停止点为空、但台词写够了 → 不判废。

**不做任何拒答文本启发式**（用户拍板）：包进 `<narrate>` 的拒答按剧作照常上演，
那是模型自己的选择，引擎不猜它的语义。判据只看「有没有可演的东西」这两件硬事实。

`beatEvents` 记账随之删除（判据不再用它，留着就是下一处漂移）。

### 2. 判废即回滚：这一轮当作没发生过

复用上下文重建那一套（`rebaseAt` 的执行体抽成 `rebuildBranchAt`，`rebaseAt` =
`guardIdle` + 它），但不落 fork 标记——这不是玩家开的新分支，是这一轮不存在：

- `tree.jumpTo(锚点)`：这一轮 append 的节点全部离开当前路径（append-only 不动它们，
  它们只是变成废弃分支，与「重来这一轮」留下的那些同性质）；
- 引擎状态 / 场景 / 活跃状态文件 / arcs / 事件缓冲 / 对话体 / 历史一起回退（同刻铁律）；
- 广播 `rebase`（epoch+1，客户端整段重放）——**判废前已经流出去的那半截**（改到一半的背景、
  只发起的一张图、被丢弃前闪过的文字）也从台上一并消失；
- 不写 `beat_end` / 不存快照 / 不切 archive / 不落盘：这一轮不该在档里留下一拍。

两个锚点，在**输入节点 append 之前**就得记下来（否则退不掉 steer 与那次选择）：

| 锚点 | 何时记 | 用途 |
|---|---|---|
| `beatAnchorId` | `beginBeat` 入口（= 本轮输入节点自己） | 重试：停在输入节点上，原样重发这一段输入 |
| `beatTailId` | 上一轮的收束处 / 每次输入入账前 | 终态退回：退到输入之前，上一轮的停止点原位复原 |

### 3. 自动重试一次：同一段输入原样重发

`beginBeat` 从「跑一轮」变成「跑到不必再跑」：`finishBeat` 判废时不写收尾，只留一条
`beatVerdict`，由 `beginBeat` 在 `await waitForIdle()` 之后消费（回滚要重建 Agent，
不能在 pi 的事件回调里做）——**发出去的还是那一段原文**（steer + 选择一起），
不是缩水的【状态】轮。次数上限 1（共两轮），重试轮的轮号与首次相同
（`restoreBranchState` 把轮号退回去，`startBeatWindow` 再 +1）。

重试的 `rebase` 带 `resuming`：客户端进等待态而不是终局态；另带一句 `note`
（「本轮没有写出内容，已退回本轮开头原样重演一次」）——舞台整个倒回去重放，
不给个说法看着就是「舞台自己抽了一下」。

**超时不重演**：网关挂住是「路不通」，再来一次只是让玩家再等一个 240s 超时。
超时照样回滚（没产出的轮不该留下），但只报错、交还出口。

**退不到锚点时不硬试**：空树上的第一轮（`start()`）没有输入节点，
`rewindFailedBeat` 直接失败，于是不会白跑第二趟（没有重建就重跑，那次拒答还在
对话体里，重跑没有意义），就地走 §4 的 pause 收尾。

### 4. 二次失败进失败态：把手上的东西还回去

退到 `beatTailId`（上一轮末尾）→ `restoreStopPoint` 让上一轮的停止点**连同选项原位复原**；
本轮注入的 steer 原文重新排回待注入队列（可改可撤，`prompt_queue` 重新下发）。
出口就是原来那些：重新选、改口径再发、点「继续」。

- 错误用 `error` 消息报（客户端 `error` toast **不会自动消失**，只有 `info` 才 4 秒退场），
  且必须发在 `rebase` **之后**——`rebase` 的处理会把客户端 error 状态清空。
- 空树上的第一轮没有可退的锚点（`start()` 直接开演、输入节点也还没落）：退不掉就
  **就地收成一个带 `pause` 出口的空轮**（等于旧行为），不把玩家的出口弄丢。

### 5. 退回处必须留下一个出口（否则失败会自我循环）

上一轮是 `no_stop`（自然演完的收尾）时，退回后 `restoreStopPoint` 给不出停止点，
而 `onBeatSettled` 的判据是「没有停止点 + 队列里有待注入的输入 → 自己开下一轮」。
判废退回恰好会把本轮的 steer 复位成 pending 放回队列——两者一撞，失败就自激：

```
失败 → 退回（无停止点）→ onBeatSettled 看见队列里有引导 → 自己开下一轮 → 又失败 → …
```

每 10~15 秒烧两次 provider 调用，error/warn toast 反复堆叠。**真机验证时实测复现**
（回归用例把 `failureExit` 关掉会挂死）。

所以判废退回必须留一个出口：`rebuildBranchAt` 收 `failureExit`，退回后若没有停止点就补
`{ stopType: "pause" }`（就是引擎自造的「重试口」，玩家按「继续」重开一轮）。
上一处本来有真停止点（选项/自由输入）时不动它——选项照旧原位复原。

## 决定

- **不引入拒答文本匹配**：判据只兜「有没有可演的产出」这件硬事实。误杀（角色台词里
  说「抱歉」）比漏判贵得多。
- **不剪枝**：被判废的节点留在谱系里当废弃分支（与「重来这一轮」同一语义），
  append-only 与 JSONL 游标都不动。代价是路线视图里会出现一张没台词的废弃卡。
- **重试不改提示词**：原样重发才叫「重演这一轮」，不塞新指令、不做格式纠偏
  （把「不肯写」当「格式错」推它继续写是另一条路，明确不要）。
- **作废那一轮的解析告警不回灌**：它属于一个不存在的轮次，回灌只会把拒答原文塞回上下文。
- **判废但已经有台词的轮不判废**：中途报错/超时但有内容的，照旧报错 + 正常收尾，
  不回滚——把玩家已经看过的内容抽走比留着更糟。
- **本轮 steer 退回：复用同一批条目**，只把 `status` 复位 `pending` 并放回队首
  （id、玩家改过的文本、`prompt_queue` 面板里的那一条都不变）。曾打算「原文重排成新条目」，
  实测代价是面板上会同时留一条幽灵「已进第 N 轮」且文案重复——已兑现的旧条目照原样作废更干净。

## 验收

`apps/server/test/orchestrator.test.ts`：

- 判据：只改场景 + 纯文本（零台词）→ 判废；纯 preload 零台词 → 判废；
  有台词但 provider 报错 → 不判废（内容留着，报错照发）。
- 重试：首次零产出 → 广播 `rebase`（`resuming` + 一句 note）→ 第二轮拿到同一段 user 输入
  （逐字相同）→ 有台词则正常收束，且第一次那份失败产物不在谱系/快照/历史里。
- 失败态：连续两次零产出 → 退回停止点（选项回到 `beat_end`/`rebase` 载荷）、
  steer 回到 `prompt_queue`（`pending`）、error 在 rebase 之后发出、谱系里不留失败轮。
- 退回处没有停止点时补 `pause` 出口，且收束后**不自己再开一轮**（见 §5）。
- 空树第一轮退不掉 → 就地 pause 收尾（旧行为）。

`pnpm --filter @stage-ai/server test` + 三包 `typecheck`；core/web 只跑受影响的用例。
