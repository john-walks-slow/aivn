# 开始游戏与全屏 用户验证

## 验证说明

- 验证对象：dsh-aivn 新会话上的「开始游戏」；舞台左上角的全屏键。
- 环境/前置条件：
  - **iPhone / iPad 上的 Safari**（验第 1 项：element fullscreen 在 iPhone Safari 上不存在，
    只有那条 CSS 兜底走得到）。
  - 一个**已装 dsh-aivn 且配了可用 provider** 的实例，工作区里有剧目（`play.json`）。
  - 真机浏览器（Chromium 系走的是另一档，覆盖不到这一项）。
- 自动化已覆盖、**不在此表**：「开始游戏」的位置（剧作家 chip 右边同一行）、按下后 START 真的
  进了会话日志、页面自动落到 AIVN、全屏键的进出与状态收敛
  （`e2e/verify-entry.mjs`，11/11）。
