# 验证：插图（CG）先备好再登场

## 用户验证（1~3 条）

1. **先备好一张插图**：工坊任一条路都行——让搭台助手出一张（`generate_image(kind="cg")` 出候选 →
   `import_asset` 入库），或素材页「CG → 生成」。期望：`assets/cg/<id>.jpg` 落地、素材页 CG 段与 CG 视图
   各多一张，`assets/manifest.json` 里那一格有描述（剧作家就是靠它认出这张画的是什么）。

2. **剧里临场用上它**：开演推进到与那张画对得上的段落。
   期望：剧作家写 `<cg id="…"/>` 让那张预先备好的插图登场（舞台整屏换成它、盖住立绘），
   而不是再出一张新的同内容插图。

3. **插图里的那段戏**：插图登场之后连着写台词时，这一次 `<actor>` 不会中途把它撤掉；
   下一次真的写了 `<actor>`（或换底 `<scene bg>`）才退回立绘演出。
   期望：能在一张画上读完一小段戏，而不是闪一句就没了。

## 未覆盖 / 已知边界

- **模型照不照这条写是自动化覆盖不到的**：提示词里现在有这条机制，但「这一幕该不该插一张画」
  属创作口径，模型可能整段不插。这条只保证它**想插时知道怎么插、且优先用已备好的那张**。
- `<actor>` 撤插图是既有行为，本次只把它写进契约、没有改引擎（改了会影响存量剧目的画面）。
- 插件线（`dsh-aivn`）还没 import `CG_RULES`，那边的剧作家暂时拿不到这一章；见 plan 的「遗留」。
