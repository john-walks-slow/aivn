# 261004 NSFW 内容隔离 用户验证

## 验证说明

- 验证对象：限制级段落按读者隔离（事件打标 + 按读者折叠 + 摘要落树 + 检索过滤 + 段落期间不压缩）
- 环境/前置条件：
  - 本地 stage-ai 服务已启动（server + web），设置页的剧作家角色已配好 **限制级（NSFW）专用模型**（否则 `enter_nsfw` 只切换提示词，不好观察基调变化）
  - 用一部可以正常进出限制级的剧目（或先演几轮日常再让剧作家 `enter_nsfw`）
  - 需要看落盘结果时，剧目数据目录为 `plays/<剧目名>/`（开发态在仓库根），其中 `memory/archive/events.jsonl` 是归档切片、`memory/arcs/` 是纪元摘要、`lineage.jsonl` 是谱系事件
- 关键概念：本轮改动约束的是**模型读到的上下文**，不是玩家看到的画面。前台原文不删属预期。

## 验证项

### 一、退出转场与摘要落点（核心）

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |

| 让剧作家进入限制级，演 2–3 轮，然后退出 | 转场比平常略长（退出那一拍要多等一次摘要 LLM 调用），不报错、不卡住 |  | 待验证 | 这是设计代价，不是故障 |
| 退出后继续几轮日常 | 剧作家基调回到日常；同时能接得上限制级段落里发生的事（摘要里的关键信息在后续剧情里体现） |  | 待验证 | 「不断片」是这一项的核心 |
