## 做了什么

原来的动词面是 OOC / 编辑 / 分岔 / 重写四原语。这次收敛成三个用户看得懂的按钮，
底下是四个正交的原语：

| 用户看到的 | 底下是什么 |
| --- | --- |
| 插一句 | `prompt`。唯一的输入通道；OOC 降级成 `OOC：` 前缀 |
| 改台词 | `edit`。纯原地的旁注，不碰世界线、不重演 |
| 重来这一幕 | `fork(拍首)` + 立刻开下一拍。中间不设停止点 |
| 路线卡上的分岔 | `fork`。只移世界线、落一条 fork 标记，不重新生成 |
| 路线卡上的跳转 | `jump`。只移挂载点，连标记都不落 |

三条硬约束：

1. **引擎不替玩家说话。** 原来的 `instruction` 字段和「重新演绎这一幕」这类提示语全部作废。
2. **重来锚在拍首。** 玩家上一次的选择原样保留，绝不重新问一遍。
3. **重来零点击。** `fork(拍首)` 之后立刻 `beginBeat`，玩家不用再点一次「继续」。

## 改了什么

- `packages/core`：谱系模型收敛为 `jumpTo` / `recordFork` / `recordEdit`；WS 协议删掉
  `rewrite`/`ooc`/`ooc_at`，加上 `fork { resume? }` / `edit` / `jump`。
- `apps/server`：编排器的 `rebaseAt(nodeId, note, { resume, mark })` 成为跳转/分岔/重来的
  公共内核；`editLine` 同步完成不重排世界线；`syncContext`/`branch`/`oocAt` 退役。
- `apps/web`：三按钮导演栏 + 排队面板（可改可撤），路线卡上的 `⑂` 角标与虚线分岔边。
