# 能力开关 用户验证

## 验证说明

- 验证对象：Agent 页的「工具开关」改成「能力开关」——页面上出现的是「管理角色」「生图」这类人话，
  不再出现任何工具 id；关掉一项即收走对应的工具、对应文件写权与提示词章节。剧作家默认**关**「管理角色」。
- 环境/前置条件：本机 dev 环境（`pnpm --filter @aivn/server start` + 浏览器打开工坊 → Agent 页）；
  至少一个**老剧目**（`play.json` 里还带着 `agents.<role>.tools` 的）。
- 不需要真跑一次完整演出；每一项都能在页面上直接看出来，或在一两句对话里看出来。
