## 二、路线视图的 CG 优先

`demo` 的谱系里一个 `cg` 节点都没有（所有 lineage 存档扫过：scene/actor/say/narrate/thought/sfx/
stop/beat_end/prompt/preload/fork），所以另造 `cgprobe2`：在 turn=3 那一拍手工插入
`{kind: "cg", attrs: {id: "cg_rooftop_confession"}}`，那一拍同时有 `scene` 背景
`bg_classroom_sunset`。

结果：卡片背景的 `src` 是
`/plays/cgprobe2/assets/cg/cg_rooftop_confession.jpg`，不是背景图。

![路线卡用 CG 作背景](<.worktrees/cg-view/docs/features/261001-cg-view/detail-route-card-cg.png>)

## 三、控制台

CG 页、舞台页、灯箱、空态都没有报错。路线视图有 `Maximum update depth exceeded`：

- 把 `RouteCanvas.tsx` + `beats.ts` 换回基线 `c0250f2` 的原文件 → 同样复现。
- 变基到 `main`（含 `edd5285`）后，把这两个文件换成 main 上的版本 → 同样复现（27 次）。

结论：**基线上已有，与本次改动无关**，本次未处理。
