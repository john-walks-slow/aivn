# aivn-image-parity 用户验证

## 验证说明

- 验证对象：本轮生图链路对齐（立绘后缀四段 / 多人编号锚点 / 自动补定妆照 / 同名跳过 / 逐剧目 `image` 段 /
  网址垫图）+ `list_assets` 拆除 + 舞台层搬进来的两处改进（立绘层级、`<scene clear/>`）。
- 前置条件：配好生图后端（设置界面里 `imageBaseUrl` + `imageModel`）；一个带角色卡（`characters/<id>.md`
  写了 `name`，或至少写全外貌）的剧目；真实出图会消耗配额。

自动化已覆盖的部分（离线 `npm run e2e:media` 41 条、`@aivn/stage` 单测 35 条、e2e 的
injection / stagehand / stage / style 模块）不需要在这里重复确认——下表只留自动化测不到的三件事。

## 验证项

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |

| 在搭台助手会话里给一个**半身**主体（`framing=half`）出定妆照，看成品 | 画到腰，不是全身；头顶上方留有一点空，主体不贴画幅上沿 | | 待验证 | |
