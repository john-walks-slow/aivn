# 验证：手动生图（舞台 CG 参考立绘 + 工坊手动出图）

本文件用于**用户实机确认**。请按顺序执行，逐项打勾。

## 前置

- `.env` 里 `STAGE_IMAGE_ENABLED=true` 且生图网关可达（见 README「生图」一节）。
- 准备一个**已有立绘**的剧目，至少两个角色有立绘，方便验证垫图顺序。
- 访问地址：见工单给出的 dev/preview URL（页面刷新后生效）。

## A. 舞台生图：参考角色立绘

| # | 操作 | 预期 | 结果 |
| - | ---- | ---- | ---- |
| A1 | 开演一轮，点导演栏「🖼 生图」 | 面板出现「参考角色立绘（按点选顺序垫图）」一行与「基于刚才演到的剧情与场景」勾选框（默认已勾） | ☐ |
| A2 | 观察立绘列表 | **只列出有立绘的角色**；没立绘的角色不出现 | ☐ |
| A3 | 依次点选角色 甲 → 乙 → 丙 | 每个选中项出现序号徽标 ① ② ③；再点一次取消选中，剩余序号自动前移 | ☐ |
| A4 | 填一句指令，保持「基于历史」勾选，提交 | 图按「当前剧情 + 你的指令 + 垫入的立绘」生成；完成后在 CG 页出现，角标「站内生成」 | ☐ |
| A5 | 取消勾选「基于历史」，**清空**指令 | 提交按钮置灰（点不动） | ☐ |
| A6 | 取消勾选「基于历史」，填一句指令后提交 | 出图只体现指令，画面里没有刚才那段剧情的痕迹 | ☐ |
| A7 | 重新打开「生图」面板 | 勾选框回到默认勾上、参考立绘清空（不记住上次选择） | ☐ |
| A8 | 直接选一个**没有立绘**的角色（可通过先记下角色 id，在后续 B 段生成一张立绘前后对比） | 该角色不出现在列表里 | ☐ |

## B. 工坊：角色立绘生成

| # | 操作 | 预期 | 结果 |
| - | ---- | ---- | ---- |
| B1 | 工坊 → 角色 → 选一个角色卡，底栏点「✨ 生成立绘」 | 弹出「生成新立绘：<角色名>」对话框，差分名可填、可选取景 | ☐ |
| B2 | 填差分名（如 `smile`）+ 一句描述，发起 | 对话框停在「生成中（预计 1~2 分钟）…」；期间可以继续操作界面（**不卡住**） | ☐ |
| B3 | 等待完成 | 对话框内直接显示生成结果图；关闭后角色卡的差分行/立绘列表出现新差分 | ☐ |
| B4 | 在某个已有差分右侧点 ✨ | 弹出「重生成立绘：<角色名> / <差分名>」，**差分名锁定不可改** | ☐ |
| B5 | 差分名填非法值（如 `Smile!`） | 提交按钮置灰；大写与符号被自动过滤成合法字符 | ☐ |
| B6 | 故意用不可达的生图地址发起 | 对话框给出错误提示（不是一直转圈） | ☐ |

## C. 工坊：背景 / CG 生成

| # | 操作 | 预期 | 结果 |
| - | ---- | ---- | ---- |
| C1 | 工坊 → 素材 → `backgrounds` 单元格 | 出现「✨ 生成」按钮（与「上传」并排） | ☐ |
| C2 | 点「✨ 生成」，填素材名 + 描述，发起 | 生成完成后素材列表出现该项；打开可见 16:9 的图 | ☐ |
| C3 | 对 `cg` 单元格重复 C1 / C2 | 同上；CG 页也能看到这一张 | ☐ |
| C4 | 用**同一个素材名**再生成一次 | 旧图被覆盖，列表里不出现重复项，也不残留旧扩展名 | ☐ |
| C5 | 在生成背景/CG 的对话框里点选参考角色立绘 | 立绘作为垫图参与生成（角色长相与立绘一致） | ☐ |

## D. 副作用与隔离

| # | 操作 | 预期 | 结果 |
| - | ---- | ---- | ---- |
| D1 | 走一次 B/C 的任意生成 | 工坊对话页**没有**新增气泡、撤销条里**没有**新增条目 | ☐ |
| D2 | 观察舞台 | 演出**不会**因为工坊出图而重演或中断 | ☐ |
| D3 | 生成进行中关掉页面再打开 | 图照样落盘；打开列表能看到（对话框本身不保证跨页面恢复等待态） | ☐ |

## E. 回归

| # | 操作 | 预期 | 结果 |
| - | ---- | ---- | ---- |
| E1 | 让剧作家自己调 `generate_image`（或在对话里让它出图） | 表现与改动前一致：工坊对话里有气泡与撤销条 | ☐ |
| E2 | 舞台空树（没开演）时点「生图」 | 按钮仍点不动 | ☐ |
| E3 | 剧作家的预埋 CG（剧本里写 `cg id`） | 照常出图并淡入，不受本次改动影响 | ☐ |
| E4 | 上传一张立绘但不绑差分映射，然后在舞台生图里选它作参考 | 该角色**出现**在列表里（目录里任意立绘都算数） | ☐ |
