# 写作参数化 用户验证

## 验证说明

- 验证对象：把「剧作家每轮写多长、停止点给几条选项、素材从哪来」从提示词建议变成可配置参数（`play.json` 的 `craft` 段 + 工坊「剧目」页的写作参数），外加四项邻接设置：剧本语言、工坊出图审批、NSFW 入口随工具开关收口、逐剧目生图模型与档位。
- 环境/前置条件：
  - 在本 worktree（`.worktrees/craft-params`）里跑起来的实例。它是独立 worktree，主仓库正在跑的 dev 实例看不到这些改动——要么在本目录起一份 dev（端口走 `acquire-port`），要么 `pnpm -r build` 后用它的 server 起一份。
  - 一个能开演的剧目（`plays/demo` 或任意已有剧目）；本轮的参数改动只对**新的一轮**生效，不用重启服务。
  - 第 3、6 项会真的出图（烧配额、每张 70~140 秒），不想花配额就跳过并在备注里写「未验」。

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |

## 验证结论

**用户批准直接合并，未逐项实机验证**（2026-10-04）。11 项验证项仍为「待验证」——自动化能覆盖的部分
（解析、渲染分支、工具读写、单测层面的能力位收口）已经在 Test 阶段跑完，剩下的都是必须真机与真交互
才能确认的现象。若后续实机发现与预期不符，按上表逐项回填并开 issue 跟进。
