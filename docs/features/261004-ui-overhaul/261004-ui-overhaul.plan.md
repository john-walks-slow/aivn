## 1. 现状批评清单

对着实拍与代码逐屏盘点，问题分四层：

**地基层（最要命）**
- 无字号阶梯：全站 11.5/12/12.5/13/13.5/14/14.5/15/16/16.5/17/18/34~52px 十几档散点，没有模数关系；间距同样 829 处 px 散值，4 基线不存在。
- 无间距/层级令牌：阴影、边框、留白各自为政；层级靠「感觉加个 shadow」。
- 单一无衬线字体栈：台词与剧名和设置表单同一张脸。galgame 的正文语法是明朝体（260930 调研里 Key/柚子社/Frontwing 一致），衬线当年因系统回退发虚被整层放弃——正确解法是打包子集字体，不是放弃衬线。
- 色彩令牌只有一层（直接语义色），无 primitive→semantic 两层结构，暗色是逐键手调不是系统产出。

**游戏半边**
- 剧目库：卡片悬停无反馈、封面无光效、metadata 平铺；「启动器认人靠封面」这件事只做到了有图，没做到像书架。
- 标题画面：菜单排版已是竖排动词，但剧名是 UI 无衬线、无 kicker、无缓推动效，底图静态——没有「主视觉时刻」。
- 台词窗：功能性达标（恒高、三态文字色、回看），视觉是「一条深色玻璃」：无角部结构、无饰线层次、铭牌是窗体延伸的舌片（非独立铭牌）；说话人没有专属色。
- 选肢卡：有标尺有序号，但无入场节奏、无悬停位移，卡片与画面的关系是「浮着」不是「悬在光里」。
- 路线树：卡片是灰盒，连线无状态（来路/去路一样细）、当前节点无旗标。
- 顶缘信息：无章节/BGM 角标（柚子社语法，260930 调研第 16 号样本）。

**工作室半边**
- 八个页签横在顶上，占据的是「工具栏」的位置，但工坊是主体工作区——专业工具（Blender/DaVinci/Linear）的收敛答案是左侧栏（L 形导航）。
- 工坊跟纸面共用浅色系：看图（生成的立绘/CG）在浅底上评不了色调；暗色工作区是 2026 年专业工具的默认（Linear/Raycast/Godot 4.6/Eagle 全部如此）。
- 对话流是「网页聊天」质感：无 agent 身份视觉、工具调用是文字行 + 缩略图、流式状态是一行「思考中…」——AI 正在做事这件事没有视觉证据链。
- 素材页/资源库：网格卡片密度与悬停预览（立绘差分连播预览这种「哇」时刻）缺失。

**动效层**
- UI 侧只有 hover 140ms 一档；无入场、无视图过渡、无 stagger；舞台侧反而有完整运动词汇（差分淡入/行为词/运镜）。一半是默片一半是电影。

## 2. 设计语言：「三种光」

产品是半个游戏、半个工作室。玩家侧是「白天的书店与夜晚的剧场」，创作者侧是「灯下的工作台」。三种场景用三种光，各自成体：

| 材料 | 承载界面 | 气质 |
|---|---|---|
| **① 纸（白）** | 剧目库 / 周目存档 / 设置（服务端那页）/ 标题门厅 | 编辑式克制：白、衬线、留白 |
| **② 幕（白玻璃）** | 舞台 / 台词窗 / 选肢 / 回顾 | 日常系 galgame：明亮、柔和 |
| **③ 台（白工作桌）** | 工坊全部 | 专业工作区：密度、层级 |
| **星图（浅色）** | 路线树 | 点阵底 + accent 流动连线 |

**配色总纲（第四轮定稿）：白 + 蓝的经典现代搭配，Material You 式 accent 派生体系。**

- 全站只有一根**种子色 `--accent`**（默认绀青 `#3e6ea8`）；纸面/玻璃/工作桌的表面色、边线、点亮色全部 `color-mix` 从它派生（表面掺 2~8%，点亮掺 12~50%）。
- 三级配置：**全局级**（设置页，现有 data-accent 预设升级为种子色）→ **剧目级**（`play.json` 可设 `accent`，进入该剧目时舞台/标题/名牌缺省跟随）→ **角色级**（角色卡 `color` 字段，名牌描边与名字色按角色显示，不跟全局）。
- 暖黄底色全面退役（含纸面左上斜光删除）；深色主题 = 同一派生体系换暗基座，不做简单反色。
- 视觉稿稿首有可点的 accent 色板（绀青/青/紫/橙/玫），点按全站实时换色，即此机制的演示。

调研的明确警示（wandr.studio 2026 游戏 UI 趋势）：**常驻游玩层克制、菜单与过渡承担美学**。所以台词窗的装饰只到「发丝线 + 低透明度角标」为止，标题画面/选肢/路线树这些「时刻性界面」才放开做。

## 3. 设计令牌 3.0（地基重写）

### 3.1 文件结构

`app.css`（5591 行）按材料拆四层，仍纯 CSS、无构建变化：

```
src/styles/
  tokens.css      # 全部 :root 令牌（见下）
  paper.css       # ① 纸面界面
  stage.css       # ② 舞台演出（原 app.css 舞台段迁移）
  bench.css       # ③ 工坊（新增）
  base.css        # reset / 焦点 / 选中 / 滚动条 / 通用组件类
```

app.css 保留为 `@import` 聚合入口（或 vite 入口直接引五张），避免一次性改完所有 import。

### 3.2 字体（本次最高杠杆的一件事）

- **打包 Noto Serif SC 可变字体子集**（思源宋体，OFL 许可）用于：剧名、标题画面、台词正文、选肢文案、路线卡片摘要。子集 = GB2312 常用 3500 字 + 全标点 + 拉丁数字，估计 2.5~4MB woff2（可变字重一个文件）。
- 界面 chrome 保持系统无衬线栈（现状），不引入 Inter/Geist——33/33 Framer 模板都在用 Inter，「撞脸」本身就是扣分项。
- 数值/HUD：`font-variant-numeric: tabular-nums`。
- CJK 硬约束照 Material 指南执行：同层级字号比拉丁方案 **+1px**、行高 **+0.1em**；台词行高 2.1（现状 2，衬线笔画需要更多呼吸）。
- 加载策略：`font-display: swap` + `document.fonts.ready` 后给 `<html>` 挂 `.fonts-in` 类，字体到位前后台词窗不加闪烁动画（避免 swap 抖动被当成 bug）。

### 3.3 字号阶梯（1.25 模数，CJK 修正后）

```
--t-caption: 11px    小型大写标签（.caps 全站统一：11px/600/0.2em/uppercase）
--t-micro:   12.5px  辅助说明、元信息
--t-body:    14.5px  界面正文
--t-h3:      16px    卡片标题
--t-h2:      20px    区块标题（衬线）
--t-h1:      26px    画面标题（衬线）
--t-display: clamp(34px, 4vw, 48px)  剧名（衬线 600）
--t-script:  19.5px  台词正文（衬线，行高 2.1）
```

违禁：阶梯外字号（现在的 13.5/16.5 之类全部归档）。`font-size` 只允许引用 `--t-*` 或由组件声明一次。

### 3.4 间距与圆角

- 间距 4 基线：`--s1:4px` 到 `--s8:64px`（4/8/12/16/24/32/48/64），违禁 4 基线外的值。
- 圆角双轨（沿用现有判断并成文）：页面卡片 `--r-tile: 3px`（近直角，AVG 身份）；浮在画面/工作台上的浮层 `--r-float: 8px`；胶囊 `999px` 只给 chip。

### 3.5 色彩：OKLCH + 两层令牌

- primitive 层：accent 种子 + `color-mix()` 派生族（表面 2~8%、边线 15~24%、点亮 12~50%），中性灰走冷调阶梯，danger/success/warn 各自成族，只做定义不直接使用。
- semantic 层：现有 `--bg/--panel/--ink/...` 键名保留（theme.css 兼容不破），实现改为**从 `--accent` 派生**；工坊走 `--bench-*` 同族派生。换种子色即全站换装（视觉稿色板已演示）。
- 暗色模式不是反色：纸面暗色/舞台暗玻璃/工坊灯下暗台各自维护 semantic 映射（现状已有三套，规范进 tokens.css）。
- accent 三级：设置页种子色（全局）→ `play.json` 的 `accent`（剧目，进入剧目时舞台侧跟随）→ 角色卡 `color`（名牌专属）。剧目 `theme.css` 继续可覆盖任何令牌。

### 3.6 动效令牌

```
--dur-1: 100ms   反馈（按压、hover）
--dur-2: 150ms   跟随（下拉、tab）
--dur-3: 200ms   过渡（面板、抽屉）
--dur-4: 300ms   场景（视图切换上限）
--dur-5: 400ms   入场（stagger 单卡）
--ease-ui: cubic-bezier(0.2, 0, 0.38, 0.9)
--ease-in: cubic-bezier(0.4, 0, 1, 1)
--ease-out: cubic-bezier(0, 0, 0.2, 1)
--stagger: 40ms
```

- `prefers-reduced-motion` 全局归零（现状已有，扩展覆盖到新动效）。
- 立绘运动令牌（`--move-ms/--act-ms` 等）原样保留——舞台那套是对的。

## 4. 游戏半边：逐屏规格

视觉基准 = mockup 第 01/02/03/04/06 屏。以下每条都是可验收的改动项。

### 4.1 剧目库（纸）

- 卡片改为「书脊感封面」：16:10 封面（背景 + 立绘右下 + 底部渐变纱 + 衬线剧名压图），下方一行 metadata（小型大写分类 + tabular 数值）。
- 悬停：上浮 6px + 一道 135° 掠光扫过封面（700ms，单次）。
- 新建/导入是**虚线空位牌**，排在网格末尾（与「玩什么」同层级但不伪装成作品）。
- 顶栏 AIVN 字标（衬线 + 0.42em 字距）与设置键；底部管理条保留。纸面**无斜光装饰**（第三轮删除）；书架容器不裁切，悬停整卡上移有呼吸空间。
- 空剧场（首启）：中央聚光插画（用引擎自己的生图能力出一张「空舞台」定稿图打包进默认主题资源）+ 「新建剧目 / 导入剧目包」双键 + 一行说明。这是每个新装的第一次见面，值得一张图。

### 4.2 标题画面（幕）—— 画面即界面（日常系，第三轮定稿）

- 底图 = 剧目封面（仅背景图，**不排立绘**），缓推 kenburns 26s alternate（reduced-motion 关闭）。**画面本身就是标题画面**，不加任何面板框。
- 纱两片：左上**斜向暗纱**（74%→50%→22%→58% 处消失，罩足剧名区）托剧名白字；左下**从左下角出发的径向白纱**（115%×78% at 4% 96%，0.97→0.88→0.4→0）托菜单——径向保证白纱不漫到左上剧名区（斜向渐变会盖住白字，第六轮踩实）。菜单字 19px/500、主项 21px/700、冷墨色。
- 剧名**左上**：衬线 + 暖白 + 柔落影（**无辉光**、无描边、无符号装饰），关键词可用 accent-bright 点缀；下挂一行小字距拉丁副题（无月牙装饰）。
- 菜单**左下竖排纯文字**：继续（主项）/ 开始新周目 / 周目 / 工坊 / **退出**；无按钮框、无标尺、无装饰点，**选中与悬停 = 左侧一颗菱形标记**（accent 填充 + 22% 光环），文字加浓。
- 右下角两行小字：剧目库 · 导出剧目包 / 版本号（tabular）。
- 前提摘要与角色 chips **不上标题画面**（剧目库卡片承担）；「继续」永远在最上。

### 4.3 舞台（幕）——重头戏

**台词窗（浮卡，维持第六轮形态）**
- 浮卡：左右下 24px、圆角 12px、白玻璃（accent 4% 淡染）+ backdrop blur；外缘发丝线 + 内缘顶部提亮。不做全宽贴底、不加渐变融入（第八轮否决）。
- **默认无饰线**（纯净玻璃）；「饰线：丰/俭」做成设置项，默认俭。
- 正文：`--t-script` 衬线、暖墨 `#3e342a`、行高 2.1、恒三行高（保留现有 min-height 机制）。
- 铭牌：**独立铭牌、微渐变底**（白 → 角色色 10% 淡染）+ 角色色描边 + 角色色名字（爱实 = 珊瑚、结月 = 蓝，见视觉稿），压在窗沿上方 14px，不做窗体舌片、无符号装饰；色取**角色卡 `color` 字段**（缺省 accent）。名牌宽度按最长语言预留溢出策略（缩字距不换行）。
- 下一页指示：右下小三角 1.4s 呼吸（暖褐）。
- 深色主题下整套切暖炭玻璃 + 米白字（同一批语义令牌翻转）。

**顶缘信息带（透明字 + 顶缘深纱）**
- 画面顶缘一道深色渐变纱（62%→24%→0，约画面上方 1/5），章节 + BGM 名（`♪ 曲名`）与右上快捷条都是**透明浅字**压在纱上（带 1px 柔影），不做药丸底。
- 快捷条纯文字小型大写（AUTO/VOICE/SKIP/LOG/HIDE），当前档 accent-bright。替换现有 Manual/VOICE/BACK/HIDE 图标组合。

**外壳侧栏与导演坞（贴边细条，皆可收起）**
- 展开态 = **贴边细条**：44px 宽、纯图标、白玻璃只圆外侧角（与台词窗同族材质）；文字标签悬停时从图标侧滑出墨色小签；激活项左缘一道 accent 短线；条底一枚收起钮。左条 = 舞台/回顾/路线/CG/工坊 + 分隔 + 第 N 周目（书签图标）+ 退出（log-out 图标）；右条 = 插一句/改写/重写/生图/停止点。
- 收起态 = **menu / pencil 圆钮 + 底部 8px 小字**（视图 / 导演，与手机浮钮完全同款，视觉稿 03+ 帧）；展开条与收缩钮都**垂直居中于「顶栏以下、对话框以上」的剩余空间**（不按全屏居中）；**不占布局空间，台词窗恒全宽**；现有「折叠/拖宽」交互保留此语义。
- 手机竖屏：两者各收成**一枚圆浮钮**（视图 / 导演），点按展开为横排图标条；台词窗全宽贴安全区。

**导演坞**
- **图标 + 文字**（图标上、10.5px 小字下），右缘竖排浮坞，悬停月色辉光——纯文字竖排已验证「尴尬」（用户反馈）。
- **手机竖屏：整坞落到底部横条**（台词窗上方、拇指区），一行四键 + 展开位（视觉稿第 07 屏）。

**选肢**
- 径向暗纱只罩背景与立绘（`.theater-dim` 在 theater-stage 内，现网已有此结构）；侧栏、快捷条、章节带、对话条全部在场、可点、不被压暗。
- 卡片：白玻璃 + 衬线文案 + 左侧 2.5px accent 标尺（hover 伸长）+ 逐张 40ms stagger 入场 + hover 右移 7px；径向暗纱中性冷调。**无数字编号**（用户定稿）。
- 「（继续）」空卡同形制无标尺（现状已对）。

**回顾（backlog）**
- 只高亮最新行（月姬重制语法）——回看滚轮翻页时历史行 70% 亮度，避免满屏等权文字。

### 4.4 路线树（幕）

- 画布：accent 淡染浅底 + 点阵网格；**连线走卡片之间的空隙**（右缘中点 → 左缘中点的 S 曲线），卡片渲染在线上层，线不穿卡。
- 卡片：白底 + CG 缩略 + 时刻（tabular）+ 衬线首句 + 角色名；当前节点 accent 边 + 「现在」旗标；**来路连线 accent 流动**（dashoffset 动画）、去路 accent 淡线、废弃支线整卡降透明降饱和。
- 选中态的 kin/doomed 标注保留现有交互，视觉换 accent/红晕描边。
- 布局仍走 routeTree.ts 单一真相源，只改渲染层。

### 4.5 回顾（backlog）—— 第 08 帧

- 纸白底（accent 3% 淡染）+ 外壳侧栏（回顾激活）。
- **只有原始输出一种模式**（第八轮定稿，不做切换）：引擎原文一行流——tabular 时间戳 + 名字色（旁白/指令灰）+ 无衬线正文 13.5px；指令行 45% 降淡。结构与现网 P1 log 一致，只换皮。

### 4.6 CG 鉴赏 / 周目存档

- CG：网格入场 stagger（40ms/张）、未解锁纯色块 + hover 揭示「未解锁」、灯箱保留。
- 存档位：现状「位号 + 时刻 + 首句」结构保留，视觉对齐纸面新令牌（衬线剧名、tabular 时刻、当前档主色顶边）。

### 4.7 手机竖屏（第二屏）

- 剧目库：单列宽卡（封面 21:9 裁切 + 底部渐变剧名）。
- 舞台（视觉稿第 07 屏）：导演坞整条落到底部横排图标键（台词窗上方、拇指区）；选肢卡全宽、标尺左置；台词窗贴安全区（`env(safe-area-inset-bottom)`）；铭牌缩小（名 + 描边，音色小注隐藏）。
- 台词字号下限 18px（移动可读性底线，调研数值）。

## 5. 工作室半边：逐屏规格

视觉基准 = mockup 第 06 屏（**白工作桌**，表面从 accent 淡染；顶栏 = 会话选择器（气泡图标 + 会话名 + ⌄），连接状态只在左轨底部出现一次；内容区左缘 = 外壳细条 44 + 工坊轨 204 + 间隙，无面包屑/tab 观感元素；深色主题切同派生体系的暗基座）。

### 5.1 壳：左轨 + 顶条 + 上下文面板

- 左轨 204px：剧目卡片头（衬线剧名 + RUN/章节）→ 八室导航（图标 + 文字，激活项琥珀灯色 + 左缘 2.5px 灯条）→ 底部连接状态。窄屏折叠为图标轨 56px，再窄（手机）抽屉化。
- 顶条 58px：面包屑（工坊 / 对话 / 第 N 会话）+ 会话胶囊 +（对话页）流式状态。
- 右侧上下文面板 340px（可折叠）：按页签内容变化——对话页显示「本剧目生成记录」，素材页显示筛选器，角色页显示选中角色档案。手机隐藏。

### 5.2 对话页（工坊的主舞台）

- 用户消息：右侧暖炭气泡（现有 chat-user 重皮）。
- 助手轮：左侧 agent 铭牌头像（剧作家 = 笔尖图标 / 搭台助手 = 灯具图标，各自固定色）+ 身份行（名字 + 角色小型大写）+ 正文。
- **工具活动卡**：`生成立绘 · manami/panic` 这类调用从「文字行 + 图」升级为活动卡——头行（状态点脉冲 + 动作名 + 状态词）+ 缩略图/参数区。进行中 = shimmer 骨架 + 状态点闪，完成 = 图就位。这是「AI 正在做事」的证据链，调研里 Cursor/Rosebud/Sudowrite 的卡片堆都收敛到这个形态。
- 流式书写态：`正在书写 ···` 三点波浪（替换「思考中…」裸文字）。
- 文件写入行保留，视觉对齐（等宽路径 + 灯色完成勾）。

### 5.3 素材页 / 资源库

- 立绘卡：封面 = neutral 差分，**hover 时差分连播预览**（每 600ms 切下一张，CSS 预载）——工坊的「哇」时刻。
- 网格密度可调（紧凑/舒适两档，localStorage）。
- 筛选 chips、搜索、灯箱、音频试听保留现有逻辑，重皮到 bench 令牌。
- 生成对话框（ImageGenDialog）：重皮 + 「进行中」态与工具活动卡同构。

### 5.4 表单基元（一次定义，设置页与工坊各页共用）

- 输入框/下拉（38px 高、白底、7px 圆角 + 右缘 ⌄）、分段控件（激活段 accent 实底）、开关（40×22 胶囊）、种子色板（圆形色钮 + 选中描边）。
- 表单卡（白底、10px 圆角、卡头 = 衬线小标题 + caps 副题）；行 = 左标签（含小字说明）+ 右控件，行间虚线分隔。

### 5.5 全局设置（纸面）—— 第 09 帧

- 左锚导航（激活项 accent 左条）+ 右表单卡纵列 + **常驻底栏**（保存/放弃固定在滚动区外，左下显示数据目录与「改动立即生效」）。
- 「界面主题」卡：主题分段（浅/深/跟随系统）+ **种子色板**（accent 三级配置的全局入口）+ 台词饰线丰/俭。

### 5.6 工坊 · 剧目 —— 第 10 帧

- 三张表单卡：基本信息（标题/开场白/双语种）/ 封面选图（缩略网格点选即设 + 「自动挑选」虚线格，选中项 accent 描边 + 对勾）/ 写作参数（六个分段控件，第一项恒「默认」）。

### 5.7 工坊 · 角色 —— 第 11 帧

- 定妆照卡片网格：立绘定妆照 + 名字（衬线）+ id 等宽小字 + persona 两行截断 + 音色试听行（圆钮播放 + 音色名）；主角卡左上角 accent「主角」角标；末位虚线「新建角色」。

### 5.8 工坊 · Agent —— 第 12 帧

- 剧作家/搭台助手双卡：头像 chip + 名字/角色 caps → 模型下拉 + 思考档分段 + 能力开关列表（一行 = 名字 + 一句后果 + 开关；locked 灰显不可关）+ 搭台助手独有「出图审批」分段（每次询问/自动）。

### 5.9 记忆 / 文件 / 素材

- 记忆卡：索引卡质感（顶部分类色条 + 等宽路径脚注）。
- 文件树：等宽字体 + 行悬停 accent-tint；素材页沿用第四帧已定规格（立绘卡 hover 差分连播）。

### 5.10 舞台浮层 —— 第 13/14 帧

- **待注入/生成中面板（顶部收缩式，骨架照现网旧版）**：紧凑卡（≈282px）挂在快捷条正下方——头行（「后台 · N 项」+ 收起钮）+「接下来要说的话」小节（句子行：状态图标 + 单行截断 + 时刻，悬停浮出 改/撤 工具）+「正在生成」小节（转圈进行中 / 划线已完成 / 失败行红显 + prompt 详情 + 手动清 ×，失败项不自动消失）；**收起后顶部只留一枚带角标的小图标**；舞台与工坊共用同一份数据，工坊内收进内容区底部。
- **输入 Modal**（插一句/改写/重写/润色共用形制，舞台浮层同族材质）：暗纱 + 白玻璃卡（backdrop blur + 发丝线 + 菱形标记 + 衬线标题 + 输入区 + 一句后果说明 + 右下 取消/送出），入场 0.26s 缩放浮现，卡片出现时舞台层 1.5px 失焦——「融入游戏界面」指的是它，不是台词条。

- 全部重皮到 bench 材质（白工作桌、accent 淡染边框与激活态、衬线用于名字/标题）。
- 角色卡：定妆照缩略 + 名字（衬线）+ persona 摘要 + 音色试听一行。
- 记忆卡：索引卡质感（顶部一条分类色 + 等宽路径脚注）。
- 服务端设置页（#/settings）留在**纸面**（它是「机器的设置」不是创作），仅对齐新令牌；分区吸顶导航（现长滚动页加 sticky 章节锚）。
- 表单控件统一：开关、下拉、分段控件三件套在 base.css 各做一次，禁止各页自造。
