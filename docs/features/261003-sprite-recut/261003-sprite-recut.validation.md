# 立绘原地重抠底 用户验证

## 验证说明

- 验证对象：工坊对话里立绘「图挺好、抠得脏」时，能不能不重新出图就把抠底修好。
- 环境/前置条件：stage-ai 服务端在跑，`.env` 里生图与 Exa 都开着（`STAGE_IMAGE_ENABLED=true`），
  有一个至少出了一立绘的剧目（工坊能出图就行）。

## 验证项

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 随便让工坊出一张立绘，出完在素材页确认 `assets/sprites/<角色id>/<差分名>.png` 已落盘 | 图出来了；`plays/<id>/media-cache/sprite-sources/<角色id>/` 下多一个同名的原片文件 | | 待验证 | |
| 在工坊对话里跟它说「这张抠得不干净，边缘有白毛边」，让它调一档重抠 | 它调 `recut_sprite` 而不是重新出图；**没有第二次出图**（对话里不再等一分多钟）；回执里贴出重抠后的图 | | 待验证 | |
| 对比重抠前后两张图的画面内容 | 是同一张画，只有边缘透明度不同；角色长相、姿势、衣服一个像素都没变 | | 待验证 | |
| 故意挑一张**抠得很脏**的立绘，让工坊重抠两三轮（每轮只调一档） | 边缘脏边逐步变干净，每轮回执都带图，用户点头即止 | | 待验证 | |
| 让它对一张「更早出的、留底还没有」的立绘执行重抠 | 如实报错说没有留底原片、只能重新出图，**没有偷偷重画** | | 待验证 | 留底是本次新增的，更早出的图都在这个范围里 |
| 在工坊「Agent」页看工具开关 | 「生图」分组下多出「重抠立绘底」，默认开着，能关 | | 待验证 | |
| 在工坊对话里让它出图时带抠底参数 | 它不再提抠底参数；出图不受影响 | | 待验证 | |
