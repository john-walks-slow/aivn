# 验证要求：创作口径外置 + 工坊提示词可配

日期：2026-10-03
分支：`feat/craft-style`（worktree：`.worktrees/craft-style`）

自动化测试已覆盖提示词文本层面的断言（`prompt.test.ts` / `workshop.test.ts` / `agentkit.test.ts` / core `config.test.ts`）。下面是自动化覆盖不到、必须实机确认的部分。

## 1. 工坊「补充要求」生效

1. 工坊 → Agent 页 → 搭台助手卡 → 「补充要求」写一句能被认出来的话，例如「回答里每次都用『属下』自称」。
2. 保存。
3. 在工坊对话里随便问一句（例：「现在有哪些角色？」）。
4. **看**：回复里出现了这句要求的效果。

清空该输入框再保存，回执里不该再带这句效果。

## 2. 剧作家卡上没有这个输入框

工坊 → Agent 页 → 剧作家卡，只有模型 / 思考档位 / 工具，**没有**「补充要求」。

## 3. 新剧目的 craft.md 会被写出来

1. 剧目库新建一部剧目。
2. 工坊对话里让它搭台（例：「开个故事校园恋爱，女主是转学生，画风清爽一点」）。
3. 工坊 → 记忆页 → 看 `memory/always/craft.md`。
4. **看**：文件里不只是画风，至少落下了四项里的多数——每轮多长、选项给几条、多久交还主导权、文风与禁忌。

如果它只写了「画风清爽」就落盘，说明工坊提示词里那段引导不够，需要加硬。

## 4. 剧作家读到了 craft.md

承接 3，开演一轮完整演出。

- **看**：台词长度与节奏是否符合 craft.md 里写的那条（例如写「每轮 6~10 句」时明显短于之前的 10–25 句）。
- **看**：`beat_done` 给出的选项条数是否符合 craft.md 里写的条数。

## 5. 生图不再有「提前几句」的等待

承接 4，让剧作家走到一个新场景（触发它排产背景图）。

- **看**：舞台是否短暂显示骨架占位后自动淡入成图（预期行为）。
- **看**：没有出现「等了很久图还没到、轮次已经结束」的尴尬空档。
