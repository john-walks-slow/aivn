## 抠底算法重写（第 7 轮，用户 2026-09-30 定稿）

原实现拿 8 个种子点取中位数当底色、逐点比较相邻像素漫延，两处都是错的：
flood 每步跟**相邻**像素比而不是跟固定底色比，误差逐跳累积，整张图会漂成「全是背景」；
8 个种子的中位数在阈值 1 下会算成 `(253,255,254)` 而不是白，等于底色自带一级误差。

新实现（`cutout.ts`）：**整圈边框逐通道中位数**取底色 → 全局色键（强阈值点做种子、弱阈值 8 邻域漫延，
跑在一份**高斯模糊副本**上）→ 4 连通域筛（贴边或 ≥`minHole` 才算背景）→ 只留最大前景连通域 →
边缘 alpha 走**闭式解 `a=(B−I)/(B−F)`** 逐像素反解，反解带宽 `edgeBand` 必须盖住抗锯齿渐变带。
**`strong` 是种子阈值、调大更狠；`weak` 是漫延半径、调大啃得深；`minHole` 是封闭块面积下限、调大更保守；
`keySmooth` 是喂给色键的那份副本的高斯半径（alpha 仍从原图解）、治 JPEG 环纹咬出的轮廓缺口；
`edgeBand` 是反解带宽。** 默认 `1/8/200/0.8/4` 是用户对着对比图定的（左下那版）。

`closeRadius`（掩膜闭运算回填缺口）一轮实验后被用户否掉、已从代码删除：闭运算会把背景一起
撑进轮廓（`r=2` 时头顶白斑 10.35% → 13.37%），而 `keySmooth` 只改掩膜形状、不动 alpha 来源，更干净。

误抠像素（`d > 8` 的一定是人物）实测：

| 强/弱 | 2d-a | 60(3D) | 61(3D) |
| --- | --- | --- | --- |
| 3/3（原） | 0 | 0 | 0 |
| **1/8** | **16 (0.003%)** | 426 (0.107%) | **10 (0.003%)** |
| 1/10 | 1828 (0.397%) | 3130 (0.786%) | 1517 (0.416%) |

三条 2D 原图按同字节喂进线上实现与独立参考实现，**三张覆盖率逐位相同**
（0.442039 / 0.383871 / 0.351346）——差异全部来自算法之外的输入，一次也没出现。

| 附带发现 | 说明 |

## 边缘 alpha 改闭式解（第 9 轮，用户 2026-09-30 定稿）

用户看立绘边缘「有很多小小的边角是刺的」。查了现成算法并实现：底色已知纯色时 alpha 有逐像素闭式解
`a = (B−I)/(B−F)`（color unmixing），不需要 trimap、不需要 GPU、不需要新依赖。
实现细节与完整实测见 `docs/references/260930-matting-edge-refine.md`。

**用户实机验收：A/B 对比图看过，明确「右边好了不是一点半点」。** modlens 复核同一张 A/B 的描述：
左图「边缘有断续的浅白亮色晕圈、硬台阶感」，右图「无白色晕圈、过渡灰阶平滑、边缘连续」。

真正被修掉的是**白边晕**：旧公式 `alpha = max(色差项, dist/2)`，而 `dist/2` 恒等于 0.5，
给边界带垫死了 128 的 alpha 地板，一圈半透明的边色落在深色舞台底上就是白边晕。
闭式解把这圈解成真实覆盖率。合成夹具（identity scale，20%/50%/80% 三档）实测：

| 覆盖率 | 真值 | 旧 | 新 |
| --- | --- | --- | --- |
| 0.2 | 51 | **255** | 51 |
| 0.5 | 128 | **255** | 127 |
| 0.8 | 204 | **255** | 204 |

已固化成 `test/cutout.test.ts`「边界带的 alpha 是反解出来的真实覆盖率，不是钉死的 128 地板」，
**在旧实现上必然失败**（第一档即 `abs(255-51)=204`）。

轮廓的锯齿本身没有被这个改动改善（几何粗糙度 源图 0.487/0.482/0.459，旧 0.487/0.478/0.489，
**新 0.487/0.474/0.457 —— 新的比旧的更贴源图**）。锯齿是模型在 768px 上画的线稿自带的 1px 阶梯，
被 1.406 倍放大到 1080 显出来的，要压只能提高出图分辨率（`imageSize: "4k"` 是否真能出高于
768x1376，**仍未测**）。

方法论教训（已写进 references）：我一度用「轮廓 alpha 抖动」当代理指标，
两次都被同一个指标骗到相反结论——**改了「多少东西被处理」就必须同时报一个与处理量无关的量**。
代理指标必须先确认和用户看到的现象是同一个东西。

单测：`test/cutout.test.ts` 12 条、`test/workshopAssets.test.ts`、`test/workshop.test.ts`——**51 全绿**，
core + server + web typecheck 干净。
