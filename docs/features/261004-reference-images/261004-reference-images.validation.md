# 通用垫图入口 用户验证

## 验证说明

- 验证对象：`generate_image` 新增统一参考图入口 `references`，**让 `neutral` 定妆照也能垫图**——用户拿一张既有角色图（剧目内文件或网址）来，工坊 agent 垫这张图出一张新角色的定妆照。
- 环境/前置条件：生图可用（本机 `STAGE_IMAGE_FORMAT=gemini` + flow2api），工坊里至少有一个剧目。

> 已在开发阶段由真实生图跑通一次（见下方证据），下面留给你在工坊里按真实交互确认。

## 验证项

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
