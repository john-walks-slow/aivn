# 验证：导演工具栏 / pending 浮层 / 回退与分支（2026-10-06）

自动化覆盖了这条链的机制面（`dsh-e2e run e2e/run.mjs director`，判据取自会话日志的会话面折叠
与自己挂的 SSE 探针）：导演栏的三格在不在、「提示」的第二岔是引导 / 打断、引导进队列又进会话
且不落成玩家台词、改写往会话里追加替换标记、舞台收到 `reset` 帧并整段重投影、剧作家重写这一拍。
下面这几条是自动化判不了的：**读起来顺不顺、快不快、像不像 AIVN 那一排键**。

## 场景（3 条）

### 1. 提示（引导 / 打断）

在一座有 `play.json` 的剧目里用「剧作家」预设开一个会话，说一句开演，等它交出停止点。

- **看哪里**：舞台右上角那排键（提示 / 改写 / 重写）与它开的弹窗；舞台右上角的「进行中」徽标。
- **看什么**：
  - ① 点「提示」，弹窗里是**引导 / 打断**两岔（没有「分岔」）；
  - ② 选「引导」写一句发出去：那句话进队列时右上角出现「进行中」徽标，点开能看到它标着
    **排队中**；等这一轮走完它变成「已送出」并从面板上退场；
  - ③ **台词条上没有多出这一行**（导演的话不是玩家说的话）——这一条最要紧；
  - ④ 再试一次「打断」：剧作家正在写的时候发，它当场停下、用你这句话接着写。
- **顺不顺**：两岔的说明文字是否说得清楚（「排进队列，随下一轮一起发送。」/「立刻停下这一轮，
  用这句接着写。」），弹窗的输入框与按钮位置和改写 / 重写那两格是否一致。

### 2. 改写 / 重写

等剧作家演完一轮（停止点摆着）时：

- **看哪里**：导演栏的「改写」「重写」两格、弹窗、以及按下去之后舞台的变化。
- **看什么**：
  - ① 点「改写」时输入框里**预填着当前这一句**，改一处提交；舞台先短促地重铺一遍，
    剧作家把这一拍重写出来（旧的那一版不再出现在画面上）；
  - ② 点「重写」留空提交：整拍重来；
  - ③ 两者在**演出进行中**都置灰（`busy`），提示那一格仍然可点；
  - ④ 重写之后这一拍**没有**多出一行玩家台词。
- **顺不顺**：重铺的那一下是否看得出来突兀（画面上应该走「空一下 → 剧作家正在落笔 → 新内容」，
  不该把整部戏从头再演一遍）；重写要不要等很久（一次重写就是一轮 LLM）。

### 3. 回退与分支

- **看哪里**：`dsh-rewind` 的回退（它自己的入口）、DSH 原生的「在新对话中分支」、
  新会话里的「AIVN」tab。
- **看什么**：
  - ① 回退到某一轮之后切回「AIVN」：舞台演到**你回退到的那个点**（不是回退前的结尾，
    也不是空的）；刷新页面仍然是那个点；
  - ② 在某一轮的最后一条消息上「在新对话中分支」：新会话切到「AIVN」时舞台**停在那一点**
    （连同那一刻的停止点），不是空舞台；
  - ③ 新会话里导演栏照常可用（提示 / 改写 / 重写）。
- **顺不顺**：这两条路上舞台重铺的速度（应该是一瞬间；重铺的是本地帧流，不打 LLM）。

## 已知取舍（不是缺陷）

- **改写要花一轮 LLM**：AIVN 的改写是原地改脚本行、不经过模型；DSH 这边的剧本就是剧作家的输出，
  「改这一句」只能是让它重写这一拍——换来的是上下文不会和画面对不上（见 README 的导演工具栏那节）。
- **生图不在这一排**：出图在搭台助手那条会话里做，插件没有舞台侧的出图落点。
- **pending 浮层只报提示与语音**：出图与配乐在插件里是同步的工具调用，没有回合之外的作业可报。
- **回退之后旧台词的语音**：重建给台词行重新编号，只有盘上已经合成过的那几句会补回「重听」；
  流式那一遍若在行中途停过 700 毫秒以上，分句与整段重算不同，那种行重建后就没有配音了。
