# 音色目录按需查询 验证

改动：`GET /api/voices` 支持 `language` / 可重复 `tag` / `q` 三个查询参数，服务端按条件现抓
Fish 对应窗口；`list_voices` 工具同步升级（`tags` 并集 + 全库标题搜索）。数据面：
语言窗口从 52 条变 1000 条（日语），二次元/角色音才真正可用。

## 用户验收（请真人过一遍）

开发服务：**https://<your-domain.com>**（局域网 `http://<本机IP>:8787`）

1. 进任意有角色的剧目 → 工坊 → **角色**页 → 角色卡的「音色」→ 开音色库面板。
2. **默认**：下拉自动落在你的浏览器语言（中文环境 = 中文），计数应是 **1000 条**（旧版这里只有
   全局热门窗口里的 86 条中文）。卡片第一排应是中文音色（丁真 / AD学姐 / 赛马娘 …）。
3. **切「日本語 / 日语」**：等「筛选中…」过去（首次 4–15 秒，之后 12 小时内秒开）→ **1000 条**，
   下方 chips 变成 anime / character-voice / young / energetic … 卡片是フェルン / 五条悟 /
   星街すいせい 这一批日语角色音（旧版日语只有 52 条，且几乎没有能用的二次元声线）。
4. 点 **anime** chip（可多选，多选是并集）→ 仍是 1000 条，但全是打 anime 标签的。
5. 搜索框输 **雷姆** → 计数 3 条（雷姆レム / 雷姆 / 拉姆雷姆）——语言筛（日语）与关键词是 AND，
   这就是「全库标题搜索」的效果。把语言切回 **全部语言** 再搜一次 → 13 条（跨语言的雷姆音色，
   热门目录里一条都没有）。「全部语言」也是切到日语之后回全局热门列表的唯一入口。
6. 任一卡片「试听」照常出声；「选用」照常写入角色卡。

**要盯的点**：切换语言/标签时「筛选中…」是否符合预期（首次十几秒是上游速度，不是本机卡）；
搜索结果是否与筛选条件自洽；试听是否照常。

## 回归面

- 基础目录（无条件 `GET /api/voices`）行为不变：12h 磁盘快照、失败沿用旧快照标 `stale`、
  失败后 5 分钟静默期。
- 角色卡里目录外的 `voiceId`（如 demo 剧目的私有音色）仍按 id 单条解析出名字与封面。
- `list_voices` 仍只装给工坊；工坊提示词里挑音色的语言仍跟剧目 `voiceLanguage` 走。

## 已知边界

- 描述/标签的本地关键词匹配被**全库标题搜索**取代：搜描述里的词不再命中（Fish 只提供标题搜索）。
  风格发现改走 chips（标签即风格）。
- 窗口只在内存缓存，服务重启后第一个日语窗口要重付一次十几秒。
- 每个语言/标签组合是各自独立的 1000 条窗口，**不同筛选下的「1000 条」不是同一批人**，
  所以语言下拉不再显示计数（会误导）。
