# 路线视图第二轮（走原路 + 三动词）用户验证

## 验证说明

- 验证对象：① 跳回旧轮后重选**同一个**选项是否走原路（不再让剧作家重写一遍）；② 路线卡片只剩三个动词（跳转 / 重写 / 删除），以及选中态、连线可读性、删除确认弹窗；③ 舞台导演栏的「重来」是否已改名「重写」。
- 环境/前置条件：一个**已经演过至少两轮**的剧目（第一轮末尾要有选项），最好其中一条枝被「重写」过（这样同一锚点下会有两条同来源的枝，才验得出「最后去过优先」）。
- 访问地址：`<tunnel-url>`（本机则是 `http://127.0.0.1:<web-port>`）。
- 已知边界：删除只落 `session.json`，`lineage.jsonl` 是只增不改的审计流——**将来若改成从 `lineage.jsonl` 重建，已删内容会复活**。当前读档只读 `session.json`，删除因此是持久的。
