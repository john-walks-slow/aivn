# stage-ai P6 验证记录

## 验证对象

①路线树是横向时间轴的树，宽屏左→右、竖屏上→下，分岔点扇开，废弃分支仍可点；②选中任一节点，底部检视栏能对它执行导演操作：岔出去 / 跳回这一拍回看 / 重生成 / 就地编辑 / 导演注；③五动词各自独立，改动只落在选中那一拍及其之后，世界线之外的分支不跟着动；④手机上竖屏全流程可用。

## 机器侧已预验

- 单测 web 13 全绿（beats 7 + routeTree 6）。routeTree 覆盖：父节点恒在子节点前且不重叠、纵向流向下兄弟左右分、x/y = 树深度、边数 = 父节点数、主线/支线命名、孤儿节点不丢、成环谱系不死循环
- `tsc --noEmit` 干净
- 浏览器实拍（camoufox，1280×800 与 412×915 两档视口）：8 节点 7 边；主线蓝实线 + 卡片「进行中」胶囊，废弃支线灰虚线半透明；点网格背景、拖拽平移、滚轮以指针为锚缩放（0.55–1.6）；选中第 14 拍 B-1 后检视栏出「岔回去 / 重生成这一拍 / 导演意图」
- 方向判据回归：点节点弹检视栏把容器从 380×712 压到 380×498，树仍保持纵向（不翻向）——判据取 `window.innerWidth >= innerHeight`，不取容器
- 缩放下限 0.55：树比屏宽时贴根显示、往右拖，不缩到看不清字；「回到起点」一键复位
- mock 谱系用 `node scripts/mockLineage.mjs [playId] [deep|flat]` 造（deep 48 事件 2 个分岔点 / flat 28 事件 1 个分岔点），不烧真模型
