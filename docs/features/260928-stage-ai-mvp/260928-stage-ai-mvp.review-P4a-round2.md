## 需求对齐

本轮复检对照计划文档（§5 D7、D9、D10 及 §9 实施阶段表）与第一轮检视清单，核查情况如下：
- **BLK-01 修复完整有效**：编排器引入了 `beatClosed` 标志与 `agent.finishTurn` 钩子，仅在模型同批发起 `beat_done` 时置位并由 `turn_end` 正式收束；普通记忆工具轮次（`read_memory_detail`/`search_archive` 等）不再错误提前收束或误触空拍护栏；`agent_end` 保留为异常/无工具生成路径的幂等兜底收束；同批调用（`beat_done` + 记忆工具）时通过 `{ action: "end" }` 兜底防止 terminate 吞没。节拍跨多工具轮次的核心契约完全兑现。
- **SUG-01（相关性排序）确认修复**：`searchArchive` 遍历 MiniSearch 返回的降序命中列表，通过 `byId` 获取切片并经 `allowed.has(slice.entryId)` 祖先链过滤后按相关性截取前 `limit` 条，彻底解决了此前按时间顺序过滤和高相关性切片丢失问题。
- **SUG-02（残留 lastStop 误判）确认修复**：`renderDirectorNote(text, acrossStop)` 将「玩家本轮未作回应」声明限制为仅在空闲态（`!busy`）越过停止点时附加，busy 态下 steer 注入不再误加此声明，保证模型续写语境准确。
- **SUG-03（快照原地污染）确认修复**：`saveSnapshot` 实现了对 `engine`（深拷贝 `affinity`、`flags`）及 `stateFiles` 的浅克隆隔离，杜绝了历史快照被后续节拍原地污染的风险，分岔恢复真值可靠。
- **MIN-01（单字中文检索）确认修复**：`cjkBigrams` 增加了 unigram 单字 token 保留，单字查询命中率得到保证，且已有专门单元测试覆盖。
- **MIN-02（一级标题正则）确认修复**：`loadCards` 一级标题解析改用精确正则 `/^#\s+(.+)$/`，容错良好。
- **MIN-03（移动端软键盘遮挡）状态**：已知推迟至 P6/P6.5 移动端专项，本轮记录备忘，不影响当前准入。
