# 局域网访问：要你实机确认的几件事

自动化能覆盖的都在 Linux 上跑过了：默认只听本机、开关打开后就地改听 `0.0.0.0` 且**端口不变**、局域网来源调放行接口被 403、dev 态回 501、指标回显给的是实际绑定端口、带着活动 WS 切换开关能自己重连。下面这几条只能在 Windows 打包版上看。

## 1. 新装默认只有本机能连

装完不碰设置，手机连同一个 Wi-Fi 打开 `http://<电脑IP>:8787` —— **应该连不上**（这是这次刻意改的默认值，关着时服务端只听 `127.0.0.1`）。电脑上的窗口自己一切正常。

## 2. 打开开关就能连

设置页 →「局域网访问」→ 勾上「允许局域网访问」→ 保存。

预期：网页掉一下线自己连回来（端口不变）；Windows 弹一次「是否允许访问网络」，点**允许**；设置页「手机该连的地址」列出 `http://<电脑IP>:8787`，手机打开它能看到剧目库。

## 3. 当时点了「取消」也能救回来

这条是这次的重点。先在弹窗上点**取消**（手机此时连不上），再点设置页里的「允许局域网访问（Windows 防火墙）」：

预期：弹 UAC → 点「是」→ 页面回一句「已在 Windows 防火墙里放行…」→ 手机能连了。**再点一次不报错、也不堆第二条规则**（规则名固定是「AIVN 局域网访问」，写之前先删同名）。

## 4. 关掉开关立刻断开

取消勾选并保存：手机上刷新应该立刻连不上，电脑上的窗口照常用。

## 附：自查

「Windows Defender 防火墙 → 高级设置 → 入站规则」搜 `AIVN`，应该只有一条「AIVN 局域网访问」。
