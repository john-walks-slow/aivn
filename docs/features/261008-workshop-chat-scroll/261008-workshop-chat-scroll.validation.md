- 已由自动化覆盖、**不重复列入**：
  - `apps/web/test/workshopChatTail.test.tsx` 6/6（落底、切页签回来自动落底、贴底跟新内容、上翻松开跟随并露键、点键回顶、自己发话吸底）；

  - 实机 Chromium 走查（脚本量取 `scrollTop` 与按钮位置/配色，见 summary 的实测值表与 `screenshots/`）。
