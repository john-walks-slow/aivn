# 导演生图 验证要求

请在真机（浏览器）上按顺序确认下面几项。前四项是功能本身，后面是回归。

## 一、导演栏能生图

1. 打开任意剧目的**舞台**视图。
2. 还没开演时：底部导演栏应有「生图」按钮，且**点不动**（悬停提示「还没有剧情可以入画」）。
3. 点「开演」，等这一轮演完。导演栏出现「提示 / 改写 / 重来 / **生图**」。
4. 点「生图」→ 弹出对话框，标题「生成插图」，提示写明「留空 = 照刚才演到的这一幕自己构图；
   填了 = 按你写的来」。
5. 填一句（例如「黄昏窗边，她刚转过头，逆光」），点「生成」。

## 二、位置与台账

6. 舞台右上角浮出**排队面板**，标题「正在生成」，有一行 `CG cg_xxx`，右边是已等待秒数。
7. 等图出（约 1 分钟）：那一行**不要立刻消失**。标题切成「刚刚完成」，这一行显示「已完成」
   并变淡，再过几秒才整块收起。
8. 左侧栏点「CG」：网格里多出一张卡，标题是刚生成的那个 `cg_xxx`，角标是「站内生成」，
   卡上摊开着生图提示词原文。
9. **图对得上戏吗**：内容应该是刚才演到的那一幕（人物、场景、光线），而不是随机画面。
   如果图完全跑偏（人物不对/场景不对/画面里冒出文字），记下提示词原文——那是提示词被截断了。

## 三、留空与失败

10. 不填任何指令直接点「生成」：应当照样出图（照剧情自己构图）。
11. 如果弹出红色错误提示（模型响应被截断 / 写不出提示词 / 生图未启用），照提示处理；
    前者再点一次生图通常就好。

## 四、回归（这次一并修的三个问题）

12. **刷新**：在有停止点的现场刷新页面，停止点面板（继续 / 选项 / 下一幕）**应当仍然出现**
    —— 修之前这里会停成「已停止但什么按钮都没有」。
13. **坏链接不炸服务**：把地址改成 `#/play/不存在/stage` 并刷新，页面给出打不开的提示，
    **服务不会挂掉**；改回真实剧目 id 刷新即可正常进入。
14. **润色**：在停止点用「✨ 润色」改一句玩家输入，结果应当是一句完整的话
    （历史上偶发被截成半句）。

## 五、回看中生图（新：按你看的那一行，不动世界线）

先演两轮以上（要有历史可回看）。

15. 把舞台往回滚，停在**前面某一句**上（比如第一轮的第二句）。
16. 在这一行点导演栏「生图」，填或不填指令都试一次。
17. 图出之后（约一分钟）你**仍然停在那一行**：画面上就是这张图。
    往前或往后翻一句，图**消失**（它属于那一刻，不跟着往下走）；翻回那一行，图又在了
    —— 刷新页面、重进舞台后也仍然在。
18. 左侧栏点「CG」：多出一张「站内生成」的卡。**看提示词原文**：它应当写的是你看的那一句
    为止的剧情，**不应出现你正看的那一句之后的台词**（这是本次改动的重点）。
19. 左侧栏点「路线」：卡片张数、分支形状与生图前**完全一样**——没有多出节点，也没有分叉。
20. 回看时贴在**玩家输入行**（你打的那句话）上生图，同样应当有图。
21. **回归**：回到世界线末尾（继续往下演）再点一次生图 —— 这一张照旧作为新的一幕插图出现，
    不挂在任何历史行上。

## 已知

- 生成图存在 `plays/<id>/assets/cg/`，生图用的提示词原文记在同目录的 `generated.json`。
- 回看中生图挂的是**行级旁注**（与「改写」同一套）：随存档走，删掉那段分支时挂在它上面的图
  会跟着清掉（你在路线视图里删掉整段时就是这个结果）。
- 若模型响应被截断（上面第 11 条），重试即可；网关侧偶发，不影响剧目数据。
