# 工坊线程上下文压缩 用户验证

## 验证说明

- 验证对象：工坊对话过长后自动压缩的行为——早期对话退出模型上下文、摘要进 A 区、对话记录一条不丢、面板出现分隔。
- 环境/前置条件：
  - 方式一（推荐，能真实触发压缩）：在 `.env` 临时把 `STAGE_WORKSHOP_CONTEXT_WINDOW` 设小（例如 `8000`）并 `STAGE_WORKSHOP_KEEP_RECENT_TOKENS=2000`，重启服务，然后在工坊里连着聊 20~30 轮。
  - 方式二（不触发压缩，只看外观）：直接跑默认配置，聊几轮确认面板没有多余元素。
  - dev 服务按 `scripts/dev-worktree.sh` 起；也可以直接在已开着的浏览器里看。

## 待跟进
