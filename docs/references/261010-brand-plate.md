# AIVN 品牌背板（quad plate）

> 定稿日期：2026-10-10。来源：应用图标改版时的一轮探索（12 种背板分割方式），取其中 h3「中轴十字分四块」那档、去掉记号单独留下背景。
> 用途：需要一块「AIVN 的底」的场合——启动页/缺省头像/水印/周边/文档封面。**当前线上图标未使用它**（图标仍是白底 + 蓝菱形），这份是存档，供以后拿来做品牌 staple。

## 4. 用法

- **压在下面**：记号（蓝空心菱形，`#1b5aa6`，线宽 80／1024）直接压在背板上，logo 与底同尺寸对齐即可——菱形内是右上与左下两块灰，蓝色在四块灰上对比都够。
- **当底纹**：需要更低调时把雪花的对比压到 1 档以内（`#f7f8fa` ↔ `#ebedf1`）。
- **缩到 48px 以下**：切分线会先糊掉、变成一块平均灰，这是可接受的——小尺寸用纯色底或直接用图标。
- **深色场合**：这份背板是浅色底。深色背景上不要给它加描边（描边会在深浅底色之间造成视觉尺寸跳变），直接把菱形记号单独放上去。

## 5. 重新生成

背板与图标同源同尺寸，改档位就是改 `quad-plate.svg` 里四个 `fill`：

```bash
# 只改灰阶/圆角，直接编辑 SVG 即可；要出 PNG：
node -e "const s=require('sharp');s('docs/references/brand/quad-plate.svg').resize(1024,1024).png().toFile('docs/references/brand/quad-plate.png')"
```

应用图标那套（含 favicon）走的仍是 `pnpm icon`，与本背板互不影响。
