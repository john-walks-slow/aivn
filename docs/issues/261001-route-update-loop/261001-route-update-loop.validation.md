# 路线视图 Maximum update depth exceeded 验证要求

## 用户验收

进任意剧目的**路线**视图，打开浏览器控制台，确认不再出现 `Maximum update depth exceeded`。

同一页面上顺带确认路线视图本身没被改坏：

- 树正常画出来，卡片数量与改动前一致。
- 卡片右下角「回到这里」「由此分岔」仍可点。
- 侧栏「镜头」段的横向/纵向/开头/最新/缩小/放大/看全树逐个点一遍，画面跟着动。
- 拖动平移、滚轮缩放仍然跟手。

## 关键回归

- 舞台、回顾、CG、工坊四个视图进出正常，切换视图不报错。
- 谱系刷新（在路线视图里跳转 / 分岔之后）卡片树跟着更新——`cards` 变了必须重新布局，不能因为这次的 memo 就冻住。
