# 空格键 = 点舞台 用户验证

## 验证说明

- 验证对象：舞台上的空格键。此前空格只做「回看往回追一句」，没在回看时等于空按；
  现在空格与点舞台同一个动作——翻下一句 / 继续生成。
- 环境/前置条件：任一剧目的舞台视图（`/play/<id>/stage`），随便一个已演过几轮的存档。

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 一轮演完、台词条提示「点击舞台继续生成」时按空格 | 与点舞台一样开新一轮，不用去点画面 | | 待验证 | |
| 台词还在打字时按空格 | 当前这句一次显完（不是跳过整句） | | 待验证 | 与点舞台第一段行为一致 |
