# 路线视图跳转/分岔与阅读位置 用户验证

## 验证说明

- 验证对象：路线视图卡片的三个动词（回到选项 / 从头重读 / 重演本轮）是否落在正确的世界线位置、是否还会误触发续写；刷新后阅读位置是否能精确回到读到的那一个字。
- 环境/前置条件：一个**已经演过至少两轮**的剧目（第一轮要带选项），最好其中一轮有分岔，才能在路线视图里看出父子关系。

## 验证项

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 进路线视图，点第二轮卡片右下角「回到选项」 | 世界线跳到该轮末尾，底部选项立刻可见；**剧作家不动笔**（没有新台词、没有新的等待态）；选项还是那一轮原来的几条 | | 待验证 | |
| 在上一步的选项里**改选另一条** | 新内容从那一轮末尾接上（不是接在旧叶子后面）；旧分支整段保留成兄弟，路线视图里是并列的两条 | | 待验证 | |
| 点同一张卡的「从头重读」 | 播放头回到**本轮第一句**、从第一个字开始重新显示；世界线没有被截断（后面几轮的卡还在树上、还在路线图里）；没有任何新生成 | | 待验证 | |
| 点同一张卡的「重演本轮」 | 这一轮被推倒重来（剧作家重新创作这一轮），新内容挂在**本轮之前那一点**之后，不挂在旧叶子后面 | | 待验证 | |
| 开场第一张卡：确认不再出现「无台词」的空卡 | 每张卡都有台词摘要；只有真正有台词的轮才有卡 | | 待验证 | |
| 在某一轮**读到一半**（正在逐字显示某句）时刷新页面 | 回到那一句、并且**停在这句已经显示到的那个字**，不是行首也不是末尾 | | 待验证 | |
| 刷新后按「继续」或点舞台 | 从那个字接着往下演，不重复也不跳段 | | 待验证 | |
