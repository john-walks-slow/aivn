# 两个 agent 的提示词缺口 用户验证

## 验证说明

- 验证对象：三处提示词改动——①搭台挑音色跟随剧目语音语言；②搭台知道 play.json 的字段面、
  改它不整篇覆盖；③剧作家建角色卡时不再被指去调它没有的工具。
- 环境/前置条件：服务在跑 + 一个可用的剧目 + 配好 TTS key（音色库要能查）。①②需要真实模型跑一轮工坊对话。
- 改动只动了提示词与一处上下文注入，**没有改任何运行时行为**——预期里所有「不生效」都是模型照提示词做的结果。

## 验证项

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 工坊对话里说「把语音语言改成日语」 | 它用 `edit` 定点改 play.json 的 `voiceLanguage: "ja"`（不新造键、不整篇 write）；去「设定」页看，语音语言已是「日本語（ja）」 | | 待验证 | 改完看 `git diff plays/<id>/play.json`，应只有一行变化 |
