# choice-echo 用户验证

## 验证说明

- 验证对象：玩家输入升格为一等舞台事件（`player_input`），删除客户端回声层。验证三个原始 bug 是否消除、新机制是否成立。
- 环境/前置条件：任一剧目进入演出，到达含选项的停止点（或自由输入停止点）；浏览器开 DevTools 便于观察 WS 消息。开发态 `pnpm --filter @aivn/server start` + `pnpm --filter @aivn/web dev` 即可。
