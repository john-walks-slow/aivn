# 立绘差分被抠成镂空 用户验证

## 验证说明

- 验证对象：立绘差分出图的色键底约束、差分垫图来源、抠底底色体检三处修复。
- 环境/前置条件：无。

## 验证项

本次**无需额外用户实机验证**，按用户指示跳过。

理由：本问题属于「盘上产物可离线量化」的一类，核心结论都能用自动化手段判定，不依赖真实设备或人工观感：

1. **根因与修复效果**已由单元测试覆盖：`cutout` 15 例（含白底/灰底被体检拦下、纯绿与纯品红不被误伤）、
   `playAssets` 52 例（含定妆照与差分两侧都断言色键底、拼接无双句点、差分垫图来源）。
2. **体检闸门的有效性**已用**历史上真实出问题的源图**离线验证：盘上 60 份源图中
   16 份色键底全部通过、44 份非色键底全部拦下，无误伤（明细见
   [`261008-sprite-variant-dirty-cutout.summary.md`](./261008-sprite-variant-dirty-cutout.summary.md)）。
3. 唯一需要「眼睛看」的部分（新出的差分成品是否还有镂空）依赖**真实生图 API**，
   按项目规范默认不跑、也不适合作为用户验收项。

## 验证结论

跳过（用户指示）。
