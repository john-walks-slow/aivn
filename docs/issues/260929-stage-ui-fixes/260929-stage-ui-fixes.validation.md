# 舞台 UI 五处修复 用户验证

## 验证说明

- 验证对象：工具条常驻 / 舞台无白边 / 台词不再挤压背景 / 「继续」按钮消失 / 幕末黑场 + 「下一幕」且无模型交代文字
- 环境/前置条件：手机浏览器打开服务地址；引擎 TTS、生图可关；验证前先在一处能停下来看的地方（选择肢、自由输入、幕末黑场）各停一次
