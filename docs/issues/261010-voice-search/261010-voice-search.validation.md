## 用户验收（请真人过一遍，两条）

1. 任一剧目 → 工坊 → **角色**页 → 角色卡的「音色」→ 面板顶部搜索框输 **雷姆**
   → 计数应是 **13 条**（不再是 0 条 / 2 条），语言下拉此时显示「**全部语言**」。
