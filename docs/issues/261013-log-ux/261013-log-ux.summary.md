# 问题修复总结：回顾 / Log 页面视觉与交互深度整改

## 问题背景与意图
用户反馈在回顾 / Log 页面（Backlog / History）存在多项严重体验缺陷：
1. **语音回放按钮显示成了一个圆**（没有图标，只有主题色实心圆点）；
2. **拖动 / 浏览历史时滚动位置会跳变**；
3. **窄屏工具栏丑陋且布局拥挤**（面板头部被折成两行悬浮、行内工具栏大胶囊遮挡角色名与正文）；
4. **窄屏布局各种不对齐**（列表边距、指令行缩进、当前行竖线、旁白空头部空白、原文卡片在浅色主题下突兀刺眼白底）。

---

## 根因分析与整改措施

### 1. 语音回放按钮显示成圆点
- **根因**：全局 `button { padding: 8px 14px }`（水平 padding 28px > 按钮固定宽度 20px）作用到 `.bl-voice` 上，导致内部 12px 的 SVG 图标被挤压至 0px 宽，视觉上只剩下背景圆形。
- **整改**：在 `packages/stage/src/stage.css` 中为 `.bl-voice` 显式设置 `padding: 0; line-height: 1;`，尺寸调整为 22×22px，并对内部 `.bl-voice svg` 设置 `flex-shrink: 0`。

### 2. 拖动时滚动位置跳变
- **根因**：`StageTheater.tsx` 中 `BacklogView` 的 `useEffect` 依赖项包含 `[headKey, entries.length, feed]`。由于 `feed` 在 `StageScreen` 中每次 `revision` 变化、后台流式推送或状态更新时都会生成全新的数组引用，即使当前台词 `headKey` 未变化，`scrollIntoView({ block: "center" })` 也会被反复执行，把正在手动拖动浏览历史的用户强行拉回目标行。
- **整改**：增加 `scrolledHeadKeyRef`，移除非必要的 `feed` 依赖。只有在首次获得有效 `headKey` 或 `headKey` 真正变更至新行时定位一次，保护用户手动滚动的浏览位置。

### 3. 窄屏工具栏拥挤、丑陋与遮挡
- **根因**：
  - 顶部工具栏：`apps/web/src/app.css` 的通用窄屏规则把 `.stage-panel-head` 设为 `flex-wrap: wrap` 并强制 `.stage-panel-actions` 独占 100% 宽度靠右，导致「回顾」和「关闭」占第一行，而分段切换器被挤落到第二行悬空。
  - 行内工具栏：触屏 `@media (hover: none)` 下三个带文字的按钮常驻显示，且 `app.css` 强制设为 `min-height: 32px`，在窄屏下形成 220px 宽的胶囊组，严重遮挡角色名和台词正文。
- **整改**：
  - 顶部工具栏：在窄屏下保持 `flex-wrap: nowrap`，标题、分段选择器与关闭按钮保持居中统一单行，整齐利落。
  - 行内工具栏：在 `packages/stage/src/stage.css` 的 `≤720px` 窄屏断点下，将 `.bl-tool` 紧凑圆钮化（28×28px 图标圆钮），文字通过 `.bl-tool-label` 隐藏并保留于 `aria-label`/`title`，给有名牌的行预留 `padding-right: 96px` 空间；触屏无名牌行自然流式排布在正文末尾，杜绝大面积遮挡。

### 4. 窄屏布局对齐与视觉一致性
- **根因**：
  - `<ol className="backlog-list">` 缺少 `margin: 0` 重置；
  - 舞台指令行 `.bl-dir` 的 `margin` 和 `padding` 与台词行左边缘不在同一垂直对齐线上；
  - 旁白行缺少发言人时依然渲染空 `<div className="bl-head">`，白白产生 23px 空白；
  - 玩家输入行 `.bl-input.is-current` 内外出现双重 2px 竖线错位；
  - 原文视图 `.hx-beat` 直接采用 `--panel`，在浅色界面主题下在深色舞台遮罩中呈现突兀刺眼的白底。
- **整改**：
  - `.backlog-list` 显式设置 `margin: 0`；
  - `.bl-dir` 统一设置 `margin: 4px 0; padding: 4px 12px;`，左框线和文字缩进与台词行及高亮指示竖线严格对齐；
  - `StageTheater.tsx` 旁白无角色和无语音时不渲染空 `.bl-head`，消除异常空白；
  - `.bl-input.is-current` 消除内层多余竖线，由外层指示线统一承接；
  - 原文卡片 `.hx-beat` 和 `.hx-entry` 统一定义深色磨砂玻璃背景与高对比度文字，并限制 780px 居中阅读轴线，无论界面深色/浅色模式均与舞台保持统一的沉浸质感。

---

## 验证与证据
- **静态检查**：`pnpm -r build`、`pnpm typecheck` 全部通过。
- **端到端真机截图测试**：在深色宽屏（1280px）、深色窄屏（390px 触屏）、浅色窄屏（390px 触屏）下通过 `vision-reader` 视觉核验，确认单行对齐、紧凑圆钮、无遮挡、无滚动跳变、深浅模式融洽统一。
- **评审结论**：通过 `reviewer` 检视并根据建议完善了混合输入设备下的防遮挡保障与显式宽高控制。
