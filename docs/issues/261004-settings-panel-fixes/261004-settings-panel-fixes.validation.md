# 设置页凭据与页脚 用户验证

## 验证说明

- 验证对象：设置页两处修复——① 未触碰保存不再清空已配凭据；② 保存 / 放弃常驻页面底部。
- 环境/前置条件：已打开前端（本机 `<http://127.0.0.1:8787>`，或你平时用的公网入口），
  且 `settings.json` 里已配好 API Key / 生图 Key（页面上显示为掩码）。改前请刷新页面取新前端。

## 验证项

| 验证步骤 | 预期结果 | 实际结果 | 状态 | 备注/证据 |
| --- | --- | --- | --- | --- |
| 打开设置页，先记下 API Key / 生图 Key 输入框是不是有掩码；什么都不改，直接点「保存设置」 | 提示已生效的项里**不含** `apiKey` / `image.apiKey`；再回剧目库开演，模型与生图照常可用（key 没被清空） | | 待验证 | 改前：这一步会把两把 key 清空 |
| 保存后回到设置页，看两个 Key 输入框 | 仍显示掩码（有内容），不是空框 | | 待验证 | |
| 在设置页上下滚动到任意位置（比如滚到最上面） | 「保存设置 / 放弃改动」始终贴在页面底部可见，不用滚到底 | | 待验证 | 手机窄屏也确认一下 |
| 改一个无关字段（如「输出上限」）后点「放弃改动」 | 该字段恢复原值；两个 Key 输入框仍是掩码 | | 待验证 | |
