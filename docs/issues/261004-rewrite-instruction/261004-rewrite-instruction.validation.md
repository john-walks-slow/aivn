# rewrite-instruction 用户验证

## 验证说明

- 验证对象：带交代的「重写 / 分岔」是否把交代落进**重演的这一轮**，而不是排进队列等下一轮；两个重写入口（路线卡片 / 舞台导演栏）的锚点与语义是否一致。
- 环境/前置条件：跑着本轮改动的 dev 实例，打开一部已有若干轮的剧目（至少演到第二轮，好看到锚点的差别）。
