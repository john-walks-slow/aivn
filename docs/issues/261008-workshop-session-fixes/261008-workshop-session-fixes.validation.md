## 核心场景

1. **流式不串台**：工坊开两个会话标签，A 正在流式生成时切到 B 标签——B 的界面不应出现 A 的字；切回 A 时 B 的字不能跑进来。点「新会话」后，后台那条仍在跑的流式内容也不应串进新会话界面。
2. **小图挂工具卡**：让工坊 agent 出一张图，生成结果小图应显示在「出图」工具行展开体里，不再单独摆在消息气泡下方。
3. **工坊设置立即生效**：Agent 页把工坊模型换成另一个，保存后直接发下一条消息，确认这轮用的是新模型（看不出模型差异时，可观察回复风格/加载的模型名；必要时在设置页换个明显不同的模型）。
4. **NSFW 文案**：工坊 Agent 页「限制级（NSFW）专用模型」、全局设置页同名项的留空提示，均应表明「剧目未单独指定时用全局设置，全局也空才用主模型」；实际切换行为与该链路一致。

## 备注

- 本实例还没有任何剧目（数据目录干净）；请用「新建剧目」或「导入剧目包」起步。
- 流式与出图两项涉及真实 LLM/生图接口：以上场景需要真机交互验证，自动化用例只覆盖了归位纯函数与会话状态机的回归。
