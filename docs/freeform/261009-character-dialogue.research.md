# 第一部分：人物

## 1. 欲望与需求（Want vs. Need）／自欺（The Lie the Character Believes）

来源：K.M. Weiland 的 Character Arc 系列（helpingwritersbecomeauthors.com）。

- **自欺（The Lie）**：开篇时人物对自我或世界持有的一种**受限的**看法。它未必是假的，只是不够用；剧情的事件让它不再好用。它是所有角色弧光的起因。
- **前史/幽灵（Ghost/Wound）**：过去的一件仍在起作用的事，它造出那个洞或那个阻塞。Want 直接由它驱动。
- **欲望（Want）**：由自欺生出的、推动情节的欲望。它是「对的解法」的**感知版本**——人物以为自己要的是这个。可以是好东西，但被想要的方式/理由是受限的。
- **需求（Need）**：自欺的解药，即故事的**主题真理**。通常不是一个物件，而是一次认识。它一直可得，但人物不愿接受，因为接受它要付出代价。
- 结论：**内在冲突 = 想要 vs 需要**，外在冲突 = 主角的目标 vs 对手的目标。两者互为镜像。
- 两个容易搞混的边界：
  - Want 不等于 plot goal（Want 是更深的渴望，plot goal 是它在情节里的具体化）。
  - 并非"Want 坏 / Need 好"。有力量的故事是**两个都想要的东西**之间的冲突（她想和爱人在一起，也需要做正确的事），而不是显然的好与坏。
- 弧光的三种形态：
  - **正变化（Positive Change Arc）**：认清并接受真理，放下自欺。
  - **负变化（Negative Change Arc）**：不能接受真理，即使拿到 plot goal 也带着道德失败。
  - **平弧（Flat Arc）**：人物一开始就持有真理，需要改变的是**周围世界/他人**；周围人要真实地抵抗，不能被他一句话说服。（常见误用：写成主角说教。）
- 节奏上的关键点（Weiland 版）：激励事件让旧观念开始失效；中点人物**看见**真理但还没放下自欺；第三幕转折点（低谷）象征旧身份的死亡，要放弃自欺像割掉自己的一部分，因此必然有挣扎；高潮是他按真理行动，真理才被证明。

## 2. Truby：心理需求 vs 道德需求

- **心理需求**：只伤害自己的缺陷（恐惧、自我欺骗、情感封闭）。
- **道德需求**：伤害他人的缺陷（残忍、操纵、冷漠）。
- 只有心理需求的故事：人物战胜心魔，却从未清算自己造成的伤害。两者都有，转变才同时涉及他如何看待自己、以及他如何对待别人。
- **角色网**：所有角色相对于彼此定义；对手是**最有能力攻击主角那个特定弱点的人**；盟友、假盟友对手各自代表对同一个道德问题的另一种回答。
- 区分角色的方法：给他们在同一个人类问题上的**根本不同的取径**，而不是不同的爱好或说话习惯。

来源：https://www.scriptreader.ai/guides/anatomy-of-story-truby ；https://www.jwelliot.com/wp-content/uploads/2024/06/John-Truby-Final-handout.pdf

## 3. Egri：编排与对立的统一

- 人物要按戏剧功能搭配：每个人在冲突中占一个**不可替代**的位置，彼此构成对立统一。
- 人物是"统一的力"：冲突与张力是人物长出来的，不是外挂的技巧。
- 前提里已含人物（character / conflict / conclusion 三段中的第一段）——换人物就是换前提。

来源：https://archive.org/stream/dli.bengal.10689.12919/10689.12919_djvu.txt

## 4. McKee：性格 vs 本性（characterization vs true character）

- **性格（characterization）**：年龄、职业、说话方式、习惯、态度——可观察的表面。
- **本性（true character）**：在**压力之下的选择**里显形。一个人的本质是他愿意冒什么险、在什么代价下做什么选择。
- 推论：想让读者看见人物是什么人，不要让他自我描述，让他**在两难里选一次**。
- 麦基同时提醒：故事结构与人物是一体的；「情节」和「人物」的对立是假问题——事件揭示人物，人物迫使事件。（Structure and Character 一章。）

来源：https://www.nomti.org/mckee-notes.html （第 9 条：Through choices made under pressure）

## 5. 人物的常见失败模式（可追溯部分）

- 人物在压力下不选、只被事件推着走（McKee：本性未被揭示）。
- 只给标签/属性，不给"面对同一问题的取径"（Truby：角色网缺失）。
- 所有人对同一事件反应相同（性格/声音未区分，见台词部分）。
- 主角无缺陷 → 做不出选择（Weiland：没有自欺就没有弧光）。
- 平弧主角靠说教改变他人（Weiland 明确指出这是误用）。
- 反派只是"坏"而不是"对同一问题的另一个答案"（Truby）。

# 第二部分：台词

## 1. McKee：台词不是对话

> "Dialogue Is Not Conversation. Tradition defines dialogue as talk between characters, but all talk responds to a need, engages a purpose, and performs an action. To say something is to do something. Therefore, beneath every line of character talk, the writer must create a desire, intent, and action. That action then becomes the verbal tactic we call dialogue."

- **台词的三个功能**（他给的自问）：这个人物为什么说话？
- **文本（text）**：说了多少、说的是什么品质的话。
- **潜台词（subtext）**：人物**没说**的是什么——外层的说辞与内层的所思所感之间的双重维度。
- 说明（exposition）的台词要"变成弹药"，用来翻转一场戏的结尾或推进冲突（与故事结构同理）。

来源：https://mckeestory.com/books/dialogue/ ；https://mckeestory.com/webinars/dialogue/

## 2. 潜台词的可操作规则（Weiland）

1. **不要说你想说的**：先把每场对话的"那件事"写下来，把人物真的说出口的地方划出来，然后想办法**从侧面说、说反话、用身体语言或叙述暗示**。
2. **让台词走一个圆**：一句话第一次出现是字面意思，第二次出现在另一个处境里，意思翻倍。（例：她把一句他早先说过的话还给他，等于回应了他，却没有一句 on-the-nose 的对白。）
3. **给意外**：直问直答最没劲。让人物误解、讽刺、说谎、岔开话题——每一种都比标准答案更能说明他是谁。
4. **淡化与反讽（understatement / irony）**：需要把话说清楚时，也能绕开 on-the-nose——用轻描淡写或反讽说出真相。
5. 身体是潜台词：嘴上说没事、手上把杯子攥到发白；读者信身体。

来源：https://www.helpingwritersbecomeauthors.com/subtext-in-dialogue/

## 3. 台词的另外几条通行规则（Writer's Digest 对"7 条常见建议"的修正）

- 不要把对话写成真实口语：现实中人说话主要为传达信息；**在小说/剧本里，对话是为了克服什么**。写的时候别问"这个人物需要说什么"，问"这个人物需要达成什么"。
  - 每个人物在这一场都有自己的目标（说服、取悦、勾引、惩罚）；**议程压过话题**。
- 可以跑题：跑题用来埋伏笔、放红鲱鱼、露出动机、加戏剧元素。琐碎的谈话本身可以承载潜台词——好莱坞的说法是"这场戏不是关于它所关于的东西"。
- 但潜台词不要滥用：追逐戏这类"所见即所得"的场面里硬加潜台词只会分散注意力。
- 不要用同一种腔调写一个人：同一个受过高等教育的人每次都掉书袋会变单薄；南方人就总说 y'all 会变刻板。**地位、语境、意图**决定他此刻怎么说话。
- 说话人标注（said/说）要节制，用它制造停顿、刻画人物、控制节奏，而不是每次都换一个同义词。

来源：https://www.writersdigest.com/write-better-fiction/rewriting-the-7-rules-of-dialogue

## 4. 潜台词的机制（为什么必须有）

- 直接表达是危险的：会招致拒绝、逼出对峙。所以人绕开说，用暗示、转移、说一件事指另一件事。
- **每个在场的人都有一个说不出口的想要**，潜台词就自动产生。两个目标互相冲突，且谁都不能直接开口 → 冲突就从字缝里渗出来。
- 潜台词要求读者工作，参与感由此而来；把话说尽，读者就是被动的。
- 操作检验：写下每个角色这场戏想要什么（具体的、当下的），逐句看它是否在推进或保护那个想要；两边是否冲突；是否有人直接说出了自己的想要。若两边都直说且不冲突 → 没有潜台词。
- **回避本身就是信息**：每次换话题、答非所问、把注意力引开，潜台词都在喊。
- **沉默是最强的潜台词之一**：问出口没人接，读者自己会填。不回答就是回答。

来源：https://thewritingking.com/subtext-characters-dont-say/ ；https://www.writingclasses.com/toolbox/ask-writer/in-dialogue-what-is-subtext （含 Fitzgerald《了不起的盖茨比》衬衫一节的细读）

## 5. 台词的常见失败模式（可追溯部分）

- on-the-nose：人物把心事/主题直接说出来（Weiland 规则 1 直接点名）。
- 信息倾泻 / unnecessary exposition：LAMP 语料里占专业编辑修改的 18%（见 ai-writing-craft）。
- 角色声音雷同：所有人都一副嗓子。
- 用对话解释设定（"正如你所知，我们是三年前成立的……"）。
- 每个人都准确说出自己的感受 → "像心理咨询记录"（原话：dialogue without subtext sounds like therapy transcripts）。
- 潜台词过度使用（连追逐戏都要有言外之意）。
- 用说话人标注的同义词堆砌代替节奏与人物。
