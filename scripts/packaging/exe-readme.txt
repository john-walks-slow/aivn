{{name}} {{version}} · 免安装 Windows 版
==========================================

三步上手
--------

1. 把整个文件夹解压到一个**有写权限**的位置（例如 D:\{{name}}\；不要放在 C:\Program Files 下面）。
2. 双击 {{name}}.exe。
3. 浏览器会自动打开 http://127.0.0.1:8787 。第一次进「设置 → 模型网关」填网关地址与 API Key、选一个模型，就能开始玩了。

关掉那个黑色命令行窗口就是退出服务。

同一局域网用手机 / 平板玩
------------------------

服务默认监听 0.0.0.0，启动时命令行里会打印一行：

    局域网  http://192.168.x.x:8787

手机连同一个 Wi-Fi，浏览器打开这个地址即可。

第一次启动时 Windows 会弹「防火墙已阻止部分功能」，要勾选**专用网络**并允许；
如果不小心点了取消，用管理员身份运行这条命令补一条放行规则（端口按命令行里显示的改）：

    netsh advfirewall firewall add rule name="{{name}}" dir=in action=allow protocol=TCP localport=8787

数据放在哪
----------

exe 同级的 data\ 目录，全部是你的东西，备份就复制这个目录：

    data\settings.json    所有设置（设置页写的就是它，手改也认）
    data\plays\           剧目（自带一个 demo 样例）
    data\library\         素材资源库
    data\media-cache\     语音、图片缓存（删了会自动重建）

换端口或换数据目录
------------------

命令行里带参数（在文件夹地址栏输入 cmd 回车，然后）：

    {{name}}.exe --port 9000
    {{name}}.exe --data-dir D:\my-plays
    {{name}}.exe --no-open          启动后不自动开浏览器
    {{name}}.exe --help             看全部参数

也可以放一个 .env 文本文件在 exe 旁边，写 STAGE_PORT / STAGE_DATA_DIR / STAGE_HOST，
效果一样。运行期的设置（网关、密钥、生图、语音、访问密码）都在设置页里，改完立即生效，不用重启。

常见问题
--------

**Windows 提示「已保护你的电脑」**：exe 没有代码签名，属正常现象。点「更多信息」→「仍要运行」。

**双击后窗口一闪而过**：多半是端口与数据目录不可写。在文件夹地址栏输入 cmd 回车，
再运行 `{{name}}.exe`，就能看到报错信息；也可以先跑一次自检：

    {{name}}.exe --selftest

它会逐条打印前端产物、技能库、样例剧目、数据目录、图片处理库（sharp/libvips）是否正常，
哪一条打 ✗ 就把那一行发出来。

**杀毒软件报毒**：pkg 打包的 exe 常被误报，加白名单即可，或从源码自行构建（见仓库 README）。

**生图 / 立绘抠底不能用**：图片处理库是打进 exe 里的原生模块，杀软有时会拦它的释放目录
（%TEMP%\pkg-*）。用 `--selftest` 确认是不是这一条，必要时把临时目录加进杀软白名单。
