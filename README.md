入口（工坊是舞台外壳的第四个视图，恒全屏，没有独立的顶栏）：
| **对话** | 与工坊 agent 的 meta-chat 多会话。会话是**这一页内部的一层**：对话页顶部一条会话头（当前会话名 + 「新会话」），点开在页内列出全部会话（切换 / 归档 / 删除）。会话只存对话，剧目文件是共享的 |
| **素材** | 剧目配置（标题 / opening / 语音语言 / 主角卡 / 角色卡与立绘差分映射）+ 背景 / CG / 音效 / BGM 上传。角色卡与主角卡各带一个「从资源库导入」入口，立绘在角色卡里传。图片直接出缩略图，点开看大图；音效和 BGM 可就地试听。世界观前提在这里**只读回显**，编辑器在「记忆」页 |
| **文件** | 剧目文件树 + 文本编辑（保存按钮；未保存有标记）。可改 `play.json` 与 `memory/**`，`assets/**` 只读——图片和音频在右侧直接预览，不进编辑器 |
| **记忆** | 剧目记忆 `memory/**`，按「剧作家怎么用」分四组：**常驻设定**（`always/craft.md` 创作口径 + `always/premise.md` 世界观前提）、**角色设定**（`always/characters/<id>.md`）、**设定卡**（`index/**`，子目录随意建）、**纪元产物**（`arcs/` 与 `archive/`，只读——它是纪元压缩自动写的，手改会绕过按分支过滤的防剧透）。`craft.md` 缺文件时看到的是内置默认口径（标「默认口径」），保存即落盘成你自己的 |
| **设置** | 演出侧开关（见上节「设置」）。与工坊对话改的是同一份文件，改完等当前这一轮写完即生效 |
